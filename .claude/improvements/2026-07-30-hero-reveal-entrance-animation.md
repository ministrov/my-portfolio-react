# Hero Reveal v2 — анимация входа по дизайн-хендоффу

Дата: 2026-07-30
Источник: `Hero Reveal.dc (1).html` + `README (1).md` (дизайн-хендофф, найден в этой же папке).
Продолжение: [2026-07-30-hero-section-redesign.md](./2026-07-30-hero-section-redesign.md) (этапы 1–6, уже выполнены и закоммичены).

## Контекст

Хендофф — high-fidelity прототип входной анимации Hero-секции с точными таймингами/easing.
Он описывает больше, чем уже сделано в этапах 1–6: построчный reveal заголовка, «bloom»-вспышку,
блик-glare, CTA с overshoot и пульсирующим кольцом, orbit-микроанимацию иконки, а также
вращающуюся conic-gradient рамку вокруг кнопки вместо статичного свечения.

## Зафиксированные решения (по итогам уточняющих вопросов)

1. **Шрифты** — НЕ переходим на Montserrat/JetBrains Mono. Остаёмся на текущих
   Oswald/Unbounded/Open Sans (новая Google Fonts зависимость не обсуждалась и не нужна) —
   тайминги/цвета/структуру берём из хендоффа, типографику маппим на существующие шрифты проекта.
2. **Анимация входа** — воссоздаём полный timeline по хендоффу (построчный reveal, bloom, glare,
   CTA pop+ring, orbit иконки) на Framer Motion (уже используется в проекте), а не на сырых CSS
   `@keyframes`, кроме бесконечных декоративных луп-анимаций (спин рамки, orbit, bounce
   scroll-hint) — они остаются на чистом CSS, как каретка логотипа и звёзды сейчас.
3. **Фон/частицы** — НЕ трогаем. Собственный слой частиц из хендоффа не добавляем,
   `AnimatedBackground` остаётся как есть (сайтовый, вне скоупа Hero).
4. **CTA-кнопка** — заменяем статичный `::before` radial-glow (этап 6) на вращающуюся
   conic-gradient радужную рамку (border spin), как в хендоффе.
5. **Цветовые токены** — используем существующие переменные проекта (`--gradient`,
   `--color-blue-700`, `--color-violet-500`, `--color-red-500`) вместо новых хардкод-hex из
   хендоффа, чтобы не плодить несогласованную палитру. Порядок и характер градиента —
   как в хендоффе (синий → фиолетовый → розовый → синий, конический).
6. **Коммиты** — как и раньше: отдельный коммит на каждый под-этап, Conventional Commits,
   английский текст, без `Co-Authored-By`, только локально.

## Под-этапы

### 7a — Kicker: track-in эффект

**Файлы:** `src/sections/hero/style.css`
Чистая CSS `@keyframes` анимация на `.hero__kicker`: letter-spacing `1.1em → 4px` (значение через
CSS custom property, чтобы не конфликтовать с адаптивным `letter-spacing` в медиа-запросах) +
`opacity 0→1` + `filter: blur(6px)→blur(0)`. Framer-обёртка `m.p` с `fadeUp` заменяется на обычный
`<p>` с CSS-анимацией (эффект всё равно one-shot при заходе на всегда-видимую above-the-fold секцию).

### 7b — Заголовок: построчный reveal + фоновая «bloom»-вспышка

**Файлы:** `Hero.jsx`, `style.css`
Каждая строка заголовка оборачивается в `overflow:hidden` контейнер; внутренний `m.span`
анимируется `y: '115%' → 0`, `rotate: 2 → 0`, `filter: blur(14px) → blur(0)`, `opacity 0→1`,
со stagger по строкам (кикер/строка1/строка2/акцентная строка). Плюс новый фоновый круг-«bloom»
позади заголовка (`radial-gradient`, `scale 0.3→1.5`, `opacity 0→0.85→0`, один прогон).

### 7c — Блик-glare по заголовку

**Файлы:** `Hero.jsx`, `style.css`
Диагональная светлая полоса (`mix-blend-mode: overlay`) пробегает по области заголовка один раз
после появления строк (`translateX -120%→220%`, `skewX(-18deg)`).

### 7d — Бегущий градиент акцентной строки

**Файлы:** `style.css`
`.hero__title-accent`: `background-size: 200% 100%` + бесконечная `background-position` анимация
(запускается после входного reveal), используя `var(--gradient)`.

### 7e — CTA: вращающаяся рамка + pop с overshoot + пульсирующее кольцо + orbit иконки

**Файлы:** `Hero.jsx`, `style.css`

- Заменить статичный `::before` (радиальный blur-glow, этап 6) на вращающийся conic-gradient слой
  (`hrSpin`-аналог, 6s linear infinite) на основе `--color-blue-700 → --color-violet-500 →
--color-red-500 → --color-blue-700`.
- Появление кнопки — `scale 0.82→1.045→1` с overshoot (`cubic-bezier(.2,1.5,.35,1)`).
- Пульсирующее кольцо вокруг кнопки — 2 прогона при появлении.
- Круглый бейдж-иконка — лёгкая orbit-микроанимация (`translate 3px/-3px`) через несколько секунд
  после появления, бесконечно.

### 7f — Scroll hint: bounce-луп

**Файлы:** `style.css`
Бесконечная лёгкая `translateY` пульсация (`alternate`) вместо статичного текста.

### 7g — Reduced motion + финальная проверка

Пройтись по всем новым анимациям (track-in, per-line reveal, bloom, glare, spin рамки, ring,
orbit, scroll-hint bounce) и убедиться, что все они гасятся/заменяются на конечное состояние под
`@media (prefers-reduced-motion: reduce)`. Скриншоты 1920/992/768/475, ru/en.
