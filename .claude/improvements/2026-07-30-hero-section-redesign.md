# Улучшение Hero-секции под референс

Дата: 2026-07-30
Референс: скриншот целевого вида хедера + Hero (предоставлен пользователем в чате, светлая тема, роль градиентной кнопки/нейтрального хедера — см. ниже).

## Цель

Поэтапно приблизить интерфейс Hero-секции и всех задействованных в ней компонентов (Header: Logo, NavDesktop, ToggleLang; AnimatedBackground; сам Hero) к референсу. Каждый этап — отдельная, самодостаточная правка с проверкой в браузере и отдельным коммитом.

## Зафиксированные решения (по итогам уточняющих вопросов)

1. **Фон (AnimatedBackground + grid-pattern)** — правим только баг сетки. Тюнинг звёзд (`DEFAULT_CONFIG` в `src/const/index.js`) не трогаем — компонент общий для всех страниц (Home/About/Projects), это сознательно вне скоупа.
2. **Кнопка «Проиграть заново»** — не добавляем.
3. **Индикатор «СКРОЛЛ ↓»** — добавляем как часть Hero.
4. **Хедер** — переделываем полностью под референс (Logo, NavDesktop, ToggleLang).
5. **Кнопка «Скачать резюме»** — полный редизайн в стеклянный градиентный стиль.
6. **Коммиты** — после каждого этапа (а внутри крупных этапов — чаще, отдельными логическими коммитами), формат Conventional Commits через `commit`-скилл, английский текст, без `Co-Authored-By`. Коммиты только локальные — пуш только по отдельной просьбе пользователя.

## Ограничения по смежному коду (проверено grep'ом заранее)

- `navMobile/MenuItem.jsx` рендерит `Icon` самостоятельно (мобильное меню) — эти иконки **не трогаем**, изменения касаются только `navDesktop/NavDesktop.jsx`.
- `Footer.jsx` использует `<Logo variant="white" />` — вариант `white` (и `monochrome`) не меняем, меняем только базовый (безвариантный) цвет, который используется в `Header.jsx`.
- `grid-pattern.png` используется только в `sections/hero/style.css` — можно заменить на чистый CSS-паттерн без риска сломать другие места.
- Нигде в проекте `<Logo text=...>` не переопределяется — можно захардкодить визуальное разбиение на «Antoshkin»/«Dev» внутри компонента, не усложняя пропсами.

## Этапы

Каждый этап: подтверждение изменений перед правкой файлов → правка → проверка в браузере (Playwright) → коммит → вопрос пользователю, двигаемся ли дальше.

### Этап 1 — Фон Hero: фикс сетки

**Файлы:** `src/sections/hero/style.css`, возможно удаление `src/assets/png/grid-pattern.png`
**Изменения:** заменить `background-image: url(grid-pattern.png)` на чистый CSS `repeating-linear-gradient` (гориз. + вертик. линии) в `.hero::before`, alpha линий задавать напрямую в цвете, убрать общий `opacity: 0.06` со слоя.
**Проверка:** скриншот 1920×1080 — фон ровный, без пятен.
**Коммит:** `fix(hero): replace grid-pattern image with CSS pattern to remove tiling artifacts`

### Этап 2 — Header: Logo (двухцветный wordmark)

**Файлы:** `src/components/logo/Logo.jsx`, `src/components/logo/style.css`
**Изменения:** визуально разбить `AntoshkinDev` на «Antoshkin» (нейтральный/тёмный) + «Dev» (акцентный синий), `aria-label` по-прежнему строится из полного `text`. Базовый цвет `.logo__link` → `--color-gray-900`. Варианты `--white`/`--monochrome` не трогаем. Каретка остаётся (fade-blink деталь бренда).
**Проверка:** скриншот хедера на Home; визуальная сверка Footer (`variant="white"`) — не должен измениться.
**Коммит:** `feat(logo): split wordmark into neutral base and blue accent`

### Этап 3 — Header: NavDesktop (без иконок, нейтральный цвет)

**Файлы:** `src/components/navDesktop/NavDesktop.jsx`, `src/components/navDesktop/style.css`
**Изменения:** убрать рендер `<Icon>` в десктопном `NavItem`; цвет `.nav-list__link` → нейтральный тёмный, синий (`--color-blue-700`) — только на `:hover`/`.active`.
**Проверка:** скриншоты 1920 и 992 (на 992 `.nav-list` уходит в `display: none`, бургер должен продолжать работать).
**Коммит:** `style(nav): remove icons and neutralize link color in desktop nav`

### Этап 4 — Header: ToggleLang (нейтральная пилюля)

**Файлы:** `src/components/toggleLang/styles.css`
**Изменения:** только цвета — обводка трека и цвет текста thumb → нейтральные (не синие). Механика слайдера (`left`/`transition`) не меняется.
**Проверка:** скриншот хедера, ручное переключение ru/en.
**Коммит:** `style(toggle-lang): use neutral colors instead of blue`

### Этап 5 — Hero: индикатор «СКРОЛЛ ↓»

**Файлы:** `src/sections/hero/Hero.jsx`, `src/sections/hero/style.css`, `src/utils/i18n/locales/ru/ru.json`, `src/utils/i18n/locales/en/en.json`
**Изменения:** новый ключ `hero.scrollHint` (ru: «СКРОЛЛ ↓», en-эквивалент), новый элемент `m.p.hero__scroll-hint` после `hero__actions`, анимация — та же схема `fadeUp` с новой задержкой `ANIMATION_DELAYS.SCROLL` (после `BUTTON`), стиль — как `.hero__kicker` (uppercase, letter-spacing, мелкий серый текст).
**Проверка:** скриншот, наличие текста в обеих локалях.
**Коммит:** `feat(hero): add scroll hint indicator below CTA button`

### Этап 6 — Hero: кнопка «Скачать резюме» (стеклянный редизайн)

**Файлы:** `src/sections/hero/Hero.jsx`, `src/sections/hero/style.css`
**Изменения** (возможно отдельными коммитами по подпунктам):

- 6a. Форма и фон: `<a download>` остаётся; `.hero__btn` — полностью скруглённая пилюля (`border-radius: 999px`), полупрозрачный светлый фон, тёмный текст (`--color-gray-900`) для контраста.
- 6b. Свечение: доп. слой (`::before`/обёртка) с blur-градиентом (розовый → фиолетовый → синий), корректно обёрнутый в `@media (prefers-reduced-motion: reduce)`, если анимируется.
- 6c. Круглый бейдж-иконка на конце вместо инлайн-стрелки.
- 6d. Доступность: `:focus-visible` состояние (сейчас `outline: none` без замены).
- 6e. Мобильная адаптация: на ≤475px кнопка `width: 100%` — проверить, что пилюля + бейдж не ломаются.
  **Проверка:** скриншоты 1920/992/768/475, hover, focus (Tab), ru/en.
  **Коммит(ы):** `feat(hero): redesign resume button with glassmorphic gradient style` (+ при необходимости `fix(hero): add focus-visible state to resume button`)
