**Автор:** Мидл (`layout-engineer`) · **Ревьюер:** Лид · **Раунд:** 1 · **Вердикт:** Approve

## Что хорошо

- **Кадры совпадают с эталоном до четвёртого знака.** Лид собрал библиотечную версию (коммит
  `15af8a0c`) в отдельном worktree и снял кадры тем же методом на обеих сборках в одном Chromium
  (`getAnimations()` → пауза → `currentTime`, 390 × 844):

  | t, мс | Открытие: съезд / поворот / средняя | Закрытие: поворот / съезд / средняя |
  | ----- | ----------------------------------- | ----------------------------------- |
  | 0     | 0 / 0° / 1                          | 45° / 8 px / 0                      |
  | 100   | 7,119 px / 0° / 0,110               | 4,955° / 8 px / 0,890               |
  | 200   | 8 px / 0° / 0                       | 0° / 8 px / 1                       |
  | 300   | 8 px / 40,045° / 0                  | 0° / 0,881 px / 1                   |
  | 400   | 8 px / 45° / 0                      | 0° / 0 / 1                          |

  Тайминги `getTiming()`: открытие — `translate` 200 мс / задержка 0, `rotate` 200 / 200,
  `opacity` 200 / 0; закрытие — наоборот. Кривая везде `cubic-bezier(0, 0, 0, 1)`.

- `transform` убран; базовые `translate: 0 0; rotate: 0deg` заданы явно — из `none` переход не
  интерполируется.
- **Reduced motion работает в обе стороны:** `transition: none` в закрытом, открытом и снова
  закрытом состоянии, анимаций — 0. Повтор селектора состояния оправдан: правило состояния (0,3,0)
  специфичнее базового (0,1,0), без повтора переход играл бы при открытии. Решение оставлено как
  есть; кастомные свойства задержек не нужны.
- Геометрия: хедер 81 px, кнопка 48 × 48; в покое центры (340; 32,5 / 40,5 / 48,5), в открытом все
  три в (350; 40,5), bbox крестика 21,92 = (28 + 3) / √2. Сдвиг `x` на +10 px при открытии — следствие
  исчезновения скроллбара из-за блокировки скролла, как и в T13.
- Рамки соблюдены: только `src/components/navMobile/style.css` и память агента. `npm run lint` —
  exit 0; `npm run test:run` — 30 файлов / 208 тестов; `npm run build` — 414 мс.
- Память мидла пополнена файлом о ловушках замера переходов (два `rAF` после клика, специфичность
  reduced motion, сдвиг скроллбара) — коммитится вместе с задачей.
