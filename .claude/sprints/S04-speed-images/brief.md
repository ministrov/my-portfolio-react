# S04 — Скорость и скриншоты

> ТЗ от заказчика. Оформлено лидом из решений пользователя 2026-11-20 (цель спринта, пропорция кадра,
> отказ от Better Stack) и из `.claude/sprints/backlog.md`.

## Цель

Посетитель быстрее видит первый экран без скачков вёрстки, а карточки проектов показывают скриншоты в
одной системе — кадр 4:3 на десктопе и 4:5 на телефоне. Выкладка и внешние адреса под контролем: файл с
сервера совпадает с проверенным, дубль `www` уходит на основной адрес.

## Что нужно сделать

1. **Скорость.** Убрать сдвиг вёрстки от подмены веб-шрифтов (CLS 0,17–0,27 на `/about`), снизить LCP
   (база: 3,8 с на `/about`, 4,4 с на главной) и разгрузить главный чанк — 86,5 kB gzip JS и 8,95 kB
   CSS грузятся с первым экраном.
2. **Система скриншотов.** Один кадр и одна пропорция у всех восьми карточек `/projects`: 4:3 выше
   768 px, 4:5 на 768 px и ниже, `object-fit: cover` сверху. Исходники — одного формата и качества, вес
   по группам устройств. Mish больше не обрезается на середине блока.
3. **Выкладка.** `.gitattributes`: `public/.htaccess` приходит с LF после `git pull` на Windows.
4. **Внешние адреса.** `https://www.antoshkindev.ru/` отвечает 200 без редиректа — нужен 301 на
   основной адрес.
5. **Долги junior'а.** Три точечные правки в карточке проекта и чистка данных `imgHeight`, которые
   вышли из карточки S01-T09.
6. **Бургер без библиотеки** (ТЗ пользователя 2026-11-20). Убрать `hamburger-react` из зависимостей:
   кнопка — нативный `<button>` на React, открытое и закрытое состояние — CSS с той же анимацией, что
   была у библиотеки (вариант Squash). Заодно закрываются дефекты `<div role="button">`: пробел не
   нажимает, `aria-controls` теряется.

## Критерии успеха

Только проверяемое:

- CLS на `/` и `/about` ≤ 0,1 — медиана трёх прогонов Lighthouse Mobile (база S03: до 0,27).
- LCP: `/about` ≤ 3,0 с и `/` ≤ 3,5 с (база: 3,8 и 4,4 с), те же условия замера.
- Главный чанк `index-*.js` — минус не меньше 8 kB gzip от 86,5; меньше — в `CHANGELOG.md` записано,
  почему.
- Все 8 карточек `/projects` на 320–1440 px: кадр 4:3 выше 768 и 4:5 на ≤ 768, картинка прижата к верху,
  пропорция файла в кадре не искажена.
- Вес файлов: мобильная группа ≤ 60 000 B, планшетная ≤ 100 000 B, десктопная ≤ 200 000 B.
- `curl -I https://www.antoshkindev.ru/` — 301, `Location` — основной адрес.
- `git check-attr eol public/.htaccess` → `eol: lf`; после `git pull` файл 1218 B, а не 1237.
- Бургер: `hamburger-react` нет ни в `src/`, ни в `package.json`; кнопка — `<button>` с
  `aria-expanded` и `aria-controls`; пробел и Enter открывают меню; анимация совпадает с боевым сайтом
  по кадрам 0/100/200/300/400 мс.
- `npm run lint`, `npm run test:run`, `npm run build` — зелёные на каждой задаче.
