   нужной пропорции (waterdel 1,56; vam-voda 1,40; only 1,39) — резать по бокам от центра, по высоте
   файл сохраняется целиком. Если уже — резать снизу, по высоте.
2. **Mish (решено 26.11):** окно сдвинуто вниз — кроп строк 102–1180 (1439 × 1079). Верх кадра —

   (кнопка заканчивается на 1162). Первый вариант (0–1078) резал десцендер «р» в подзаголовке —
   пользователь его забраковал. Шапка сайта в кадр не входит: следствие сдвига окна фиксированной
   высоты.
3. **Ratingus (пересмотрено 26.11):** единственный без планшетного и мобильного исходников. Первый
   вариант — кроп 4:5 по центру — забракован пользователем: он режет текст страницы по обоим краям

   телефон; отдельного мобильного файла нет — на 375 плотность 2,16, как до T07.
4. **Формат и качество:** WebP, `quality=85, method=6`. Если файл не входит в потолок — 80, ниже не
   опускать без лида.
5. **Потолки веса:** мобильная группа ≤ 60 000 B, планшетная ≤ 100 000 B, десктопная ≤ 200 000 B.
