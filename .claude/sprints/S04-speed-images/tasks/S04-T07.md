   нужной пропорции (waterdel 1,56; vam-voda 1,40; only 1,39) — резать по бокам от центра, по высоте
   файл сохраняется целиком. Если уже — резать снизу, по высоте.
2. **Mish:** 1439 × 3024 при 4:3 сверху показывает 0–1079 px. Записать, на чём заканчивается кадр;
   если обрыв идёт посередине блока — предложить пользователю вариант смещения окна (по белой полосе
   1163–1219 из S03-T20), самовольно не смещать.
3. **Ratingus** — единственный без планшетного и мобильного исходников. Сделать оба из 1200 × 900:
   кроп 4:5 сверху, ширина не больше нативной. В отчёт — фактическое качество против остальных.
4. **Формат и качество:** WebP, `quality=85, method=6`. Если файл не входит в потолок — 80, ниже не
   опускать без лида.
5. **Потолки веса:** мобильная группа ≤ 60 000 B, планшетная ≤ 100 000 B, десктопная ≤ 200 000 B.

## Критерии приёмки

- [ ] 24 файла: десктоп 4:3, планшет и мобильный 4:5; пропорция файла = пропорция кадра ±0,001.
- [ ] Вес по группам в потолках; итоговая сумма и таблица «до/после» — в отчёте.
- [ ] Видимая часть каждого файла совпадает с прежней (кроме срезанных полей), ширина не уменьшена.
      Уточнение лида: «ширина не уменьшена» — про кадр на экране; у `only`, `vam-voda`, `waterdel` ширина
      файла неизбежно меньше 1405, потому что их исходник шире 4:3 и режется по бокам.

      видимая часть та же, что до задачи.

- [ ] `npm run lint`, `npm run test:run`, `npm run build` — без ошибок.
