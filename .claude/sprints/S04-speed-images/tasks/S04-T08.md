# S04-T08 — `www` → основной адрес, 301

**Исполнитель:** Пользователь (панель) + Лид (шаги и проверка) · **Оценка:** 1 SP · **Статус:** Done
**Зависит от:** — · **Ветка:** `sprint/S04-speed-images`

## Контекст

`https://www.antoshkindev.ru/` отвечает **200 без редиректа** — лид проверил `curl` 2026-11-20. Для
поисковиков это дубль сайта: две версии одного адреса делят вес и путают канонические ссылки
(`sitemap.xml` и `<link rel="canonical">` указывают на `https://antoshkindev.ru`).

## Что сделать

1. Лид до выдачи готовит шаги по актуальной документации Timeweb и панели — не по памяти; каждый шаг
   сверен с источником и пройден лидом, насколько позволяет доступ.
2. Пользователь включает редирект `www.antoshkindev.ru` → `antoshkindev.ru` со статусом **301**,
   сохраняя путь и схему `https`.
3. Лид проверяет `curl`:
   - `https://www.antoshkindev.ru/` → 301, `Location: https://antoshkindev.ru/`;
   - `https://www.antoshkindev.ru/about` → 301 на `https://antoshkindev.ru/about` (путь сохранён);
   - `http://www.antoshkindev.ru/` → цепочка без петель, финал — `https://antoshkindev.ru/`;
   - `https://antoshkindev.ru/`, `/about`, `/projects` — по-прежнему 200.
4. Если панель не умеет редирект — правило в `public/.htaccess` (тогда это правка кода: отдельный
   коммит с `Refs: S04-T08`).

## Критерии приёмки

- [x] `curl -I https://www.antoshkindev.ru/` — 301 и `Location` на основной адрес. Проверено
      26.11.2026: `301 Moved Permanently`, `Location: https://antoshkindev.ru/`.
- [x] Путь и схема сохраняются: `/about`, `/projects`, корень. Проверено: `www/about` → 301 на
      `https://antoshkindev.ru/about`; `www/projects?lang=en` → 301 на `/projects?lang=en` (query тоже
      сохранён); `http://www/` → `https://antoshkindev.ru/`.
- [x] Основной адрес отвечает 200 на всех трёх страницах. Проверено: `/`, `/about`, `/projects` → 200.
- [x] Нет петли редиректов: `curl -I --max-redirs 5` проходит. Проверено: по одному редиректу на
      каждом адресе, финал — 200; HTML после перехода байт в байт равен основному адресу.
