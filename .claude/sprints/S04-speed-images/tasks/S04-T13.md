## Контекст

Заказчик хочет убрать из зависимостей `hamburger-react` и собрать бургер нативно: кнопка — обычный
`<button>` на React, её открытое и закрытое состояние — на CSS. Задача — первая из трёх: разметка и вид.
Анимацию перехода (T14) делает мидл, удаление библиотеки, клавиатуру и тесты (T15) — лид.

Зачем: библиотека рендерит `<div role="button">`. Он не нажимается пробелом и теряет `aria-controls` —
совпадает с пунктами бэклога S01-T08. Нативная кнопка даёт и то и другое бесплатно.

## Что сейчас

- `src/components/navMobile/HamburgerButton.jsx:2` — импорт `Squash` из `hamburger-react`; строки 57–66 —
  `<Hamburger toggled size={28} toggle color="#0058a7" label aria-expanded aria-controls>`.
- Там же строки 25–48 — обходной трюк `isEnterDownOnBurgerRef` (keyup Enter библиотеки). **Не трогать:**
  его снимает лид в T15, после проверки клавиатуры в браузере.
- `src/components/navMobile/style.css:106–110` — блок `≤ 767 px`, `.nav-mobile__buttons` (flex, gap
  0.45rem). Стилей самой кнопки нет: их даёт библиотека.
- Как библиотека выглядит при `size={28}` (лид прочитал исходник, 2026-11-20): контейнер **48 × 48**,
  полоски **28 × 2 px**, `left: 10px`, `top: 15 / 23 / 31 px`, цвет **#0058a7**.

## Почему не просто…

- **…оставить `<div role="button">`?** Тогда пробел не работает, `aria-controls` теряется, а Tab и
  Enter приходится изображать руками — ровно то, от чего заказчик уходит.
- **…взять `<span tabIndex={0}>`?** Фокус есть, ролей и клавиш — нет: то же самодельное колесо.
- **…оставить цвет `#0058a7`?** Это кобальт старой палитры: в CSS-переменных проекта такого нет,
  `--color-blue-700` = `#2563eb`, и весь хедер — на нём. **Решение лида:** полоски — `var(--color-blue-700)`,
  маленькое видимое отличие от прежнего цвета подтверждаешь на проверке.
- **…сделать кнопку меньше 48 × 48?** Прежняя зона нажатия — 48 × 48; сжимать её — шаг назад по
  доступности (минимум 44 px).

## Что сделать

Перед кодом — **пересказ в чат**: что меняешь и по какому признаку поймёшь, что готово (критерий
готовности — твой).

1. **`HamburgerButton.jsx`:** вместо `<Hamburger>` — `<button type="button">` с тремя полосками-`<span>`
   внутри. У кнопки: класс блока `nav-mobile__burger`, `aria-label` из тех же ключей
   (`mainNav.showMenu` / `mainNav.hideMenu`), `aria-expanded={isOpen}`,
   `aria-controls="mobile-navigation-menu"` (у меню этот id уже есть —
   `MobileMenu.jsx:91`), `onClick={onToggle}`. Обёртку `div.nav-mobile__buttons` и трюк с Enter
   оставить.
2. **`navMobile/style.css`, в блоке `≤ 767 px`:** кнопка 48 × 48, `position: relative`, без рамки и
   фона, `padding: 0`, `cursor: pointer`, `flex-shrink: 0`. Полоски — `position: absolute`, `left: 10px`,
   `width: 28px`, `height: 2px`, `background: var(--color-blue-700)`, `top: 15 / 23 / 31 px`.
3. **Открытое состояние — через `aria-expanded`, без класса-переключателя:**
   - верхняя полоска: `translateY(8px) rotate(45deg)`;
   - нижняя: `translateY(-8px) rotate(-45deg)`;
   - средняя: `opacity: 0`.
     Переходы (тайминги, задержки) **не пишешь** — их добавит мидл в T14.
4. **Кольцо фокуса:** `:focus-visible` — 2 px `var(--color-blue-700)`, `outline-offset: 2px`, радиус 4 px
   (образец — `.project-card__toggle:focus-visible`). Библиотека рисовала браузерное кольцо.
5. **Проверки:** `npm run lint`, `npm run test:run`, `npm run build`. Тесты новой кнопки лид готовит на
   старте задачи и коммитит вместе с твоей разметкой — твоя разметка должна их закрыть.
