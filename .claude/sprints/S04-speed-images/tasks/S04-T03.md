# S04-T03 — Шрифты: CLS через метрические фолбэки и preload

**Исполнитель:** Лид · **Оценка:** 3 SP · **Статус:** To do
**Зависит от:** T02 · **Ветка:** `sprint/S04-speed-images`

## Контекст

На `/about` CLS 0,17–0,27 при норме 0,1 (база S02 и итоговый замер S03: 0,169 в одном прогоне из трёх).
Lighthouse называет причину: загрузка веб-шрифтов Golos Text, Unbounded и Oswald — текст
перестраивается, когда шрифт заменяет запасной. Сдвигает один элемент — абзац `.about-story__para`.

Сейчас в `src/styles/main.css:1–59` семь `@font-face`, у всех `font-display: swap`, метрического
фолбэка нет; в `index.html` нет ни одного `preload`.

## Что сделать

1. **Метрические фолбэки.** Для Golos Text, Oswald и Unbounded — `@font-face` с `src: local(...)`,
   `size-adjust`, `ascent-override`, `descent-override`, `line-gap-override`, рассчитанными под
   реальные метрики файлов. Имена фолбэков — отдельные семейства, подставленные в `--font-*` первыми.
   Цель — текст при подмене не меняет высоту строки и ширину настолько, чтобы давать CLS.
2. **Preload критичных начертаний.** Oswald 400 и Golos Text cyrillic/latin — в `index.html`
   `<link rel="preload" as="font" type="font/woff2" crossorigin>`. Адреса Vite хеширует, поэтому два
   критичных файла переезжают в `public/fonts/` со стабильным путём; `main.css` ссылается на `/fonts/…`.
   Остальные начертания остаются в `src/assets/fonts/`. Это решение можно оспорить замером: если
   preload из `public/` не даёт выигрыша — откатить его, фолбэки оставить.
3. **Замер:** Lighthouse на `/` и `/about` RU и EN по 3 прогона, как в T02.

## Заметки по ходу

**Поправка базы T02.** Три прогона T02 дали CLS 0 на `/about` RU, и на этом основании задача была
переформулирована: «проблема ушла». Повторные шесть прогонов **той же сборки** дали 0,169 / 0,180 /
0,169 / 0 / 0 / 0,180 — медиана 0,169. Премиса карточки верна; поправка внесена в
[baseline.md](../baseline.md), раздел «Поправка к CLS».

**Калибровка фолбэков.** Считал не по `xAvgCharWidth` из OS/2 — он занижает ширину Arial на
кириллице на 15–25 %. Мерил в Chrome ширину эталонных строк веб-шрифтом и фолбэком при 100 px.
Вторая ловушка: жирность браузер у фолбэка синтезирует, не меняя ширины глифов, поэтому Oswald и
Unbounded сведены по тем начертаниям, в которых стоят на сайте (капс 600/700 и герой 700). Кириллица
и латиница дают разное отношение к Arial, а `size-adjust` один на семейство — итог посередине.
Результат в браузере: ширина ±0,9 % (Golos), ±3,9 % (Oswald), ±2,1 % (Unbounded), высота строки 0 %.

**Три варианта, замер каждого:**

| Вариант                                         | CLS `/about` RU   | LCP `/about` RU | FCP `/about` RU | LCP EN (главная / about) |
| ----------------------------------------------- | ----------------- | --------------- | --------------- | ------------------------ |
| База                                            | 0,169 (медиана 6) | 3,72 с          | 3,49 с          | 4,21 / 3,41 с            |
| A — только фолбэки                              | 0,076 (3 прогона) | 3,80 с          | 3,49 с          | 4,21 / 3,48 с            |
| B — фолбэки + preload Golos и Unbounded (53 КБ) | 0 (5 из 6)        | 3,73 с          | 3,04 с          | 4,36 / 3,73 с            |
| C — фолбэки + preload Golos (22 КБ)             | 0 (6 из 6)        | 3,73 с          | 3,34 с          | 4,36 / 3,51 с            |

**Почему C.** A не убирает сдвиг полностью (один прогон 0,164). B убирает его, но 53 КБ кириллицы,
предзагруженные на англоязычной странице, отодвигают латинский шрифт: LCP EN 4,36 и 3,73 при базовых
4,21 и 3,41. C закрывает виновника сдвига (Golos Text, абзац `.about-story__para`) за 22 КБ и
возвращает EN-метрики к базовым.

**Остаточные ограничения, честно:**

- Латиница не предзагружается: на EN-страницах CLS 0 в двух прогонах из трёх, в третьем 0,063 — ниже
  порога, но не ноль. Предзагрузка латиницы добавила бы 38 КБ всем посетителям.
- LCP EN выше базы на 0,10–0,15 с. Один и тот же билд в разных прогонах даёт LCP 3,82–4,36 с, так что
  отделить эффект 22 КБ от разброса тремя прогонами нельзя. Решение — за пользователем.
- TBT `/about` RU: 100 мс в базе → 136 мс. Порог 200 мс, зелёный, но рост есть: предзагрузка — это
  лишний запрос в конкурсе за полосу.
