# S04-T15 — Убрать `hamburger-react`, клавиатура и тесты

**Исполнитель:** Лид · **Оценка:** 2 SP · **Статус:** To do
**Зависит от:** T14 · **Ветка:** `sprint/S04-speed-images`

## Контекст

После T13 и T14 бургер работает на нативном `<button>` и CSS, но библиотека ещё в зависимостях, а в
`HamburgerButton.jsx` живёт обходной трюк `isEnterDownOnBurgerRef` — он был нужен, потому что
`hamburger-react` включал меню по **keyup Enter**, а пункты меню-ссылки срабатывают по keydown. У нативной
кнопки Enter даёт click уже на keydown — тому же нажатию нечего переоткрывать меню.

## Что сделать

1. **Тесты** (правило адаптации: у junior'а тесты — за лидом):
   - `HamburgerButton.test.jsx` сейчас проверяет keyup-механику библиотеки — переписать под нативную
     кнопку: клик переключает `onToggle` с `true`/`false`; `aria-expanded` следует состоянию;
     `aria-controls` указывает на `mobile-navigation-menu`; подпись меняется RU/EN.
   - Добавить регрессию: одинокий `keyup Enter` на кнопке ничего не переключает — это документирует, что
     прежняя причина трюка отсутствует.
   - `Header.test.jsx:41` — комментарий про `<div role="button">` устарел; проверить, что поиск кнопки по
     роли и подписи работает.
2. **Снять трюк:** удалить `isEnterDownOnBurgerRef` и три обработчика из `HamburgerButton.jsx`; обёртку
   `div.nav-mobile__buttons` решить по месту — если она держит только flex-раскладку, оставить.
3. **Зависимость:** `npm uninstall hamburger-react`; `package.json` и `package-lock.json` меняются
   только этой записью. `npm audit` — без изменений (16 moderate, прод 0).
4. **Браузер (Chrome, ≤ 767 px):**
   - клик, Enter и **пробел** открывают и закрывают меню — пробел раньше не работал;
   - Enter на пункте меню закрывает меню и **не открывает его снова** (ручной сценарий: Tab на пункт,
     Enter, затем keyup на бургере);
   - после закрытия фокус возвращается на бургер (`lastFocusedRef` в `MobileMenu.jsx:63`);
   - `aria-controls` виден в DevTools, id у меню есть.
5. **Вес:** записать размер главного чанка до/после (`index-*.js`, gzip) — библиотека уходит из бандла.
6. **`CHANGELOG.md`** — запись по задаче.
