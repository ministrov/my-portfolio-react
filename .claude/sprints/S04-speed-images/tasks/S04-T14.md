## Контекст

но переход в крестик мгновенный. Заказчик просил **ту же анимацию**, что была у `hamburger-react`

## Решения лида

- **Разметку не меняем.** Библиотека делала две фазы вложенными div: внешняя группа едет, вложенная
  полоска поворачивается. У нас один элемент на полоску, поэтому вместо новых элементов —
  **индивидуальные свойства `translate` и `rotate`**: каждое анимируется своим переходом со своей
  задержкой. `transform` из открытых правил убрать, иначе движение удвоится.
- **Задержки — свои у каждого состояния.** Базовое (закрытое) правило: поворот без задержки, съезд
  с задержкой 0,25 с. Открытое правило: съезд без задержки, поворот с задержкой 0,25 с. Переход
  берётся из правила того состояния, в которое идём, — так и получается обратный порядок.
- **Поддержка:** `translate`/`rotate` — Chrome 104+, Firefox 72+, Safari 14.1+; цель сборки Vite 8
  (`baseline-widely-available`) их включает. Юник-проверка не нужна.
- **`prefers-reduced-motion: reduce`** — переходы выключаются, состояние меняется мгновенно, как до
  T14. Отдельный блок в конце файла (прецедент — `src/components/projectCard/style.css:415`).
- **Проверка кадров — числами, не записью экрана:** `document.getAnimations()` плюс `currentTime`
  на 0 / 125 / 250 / 375 / 500 мс, на открытии и на закрытии.

## Что сделать

1. **`--first` и `--third`.** В базовом правиле — переходы: `rotate` 0,25 с без задержки, `translate`
   0,25 с с задержкой 0,25 с. В открытом правиле — `translate: 0 ±8px`, `rotate: ±45deg` и обратные
   задержки: `translate` без задержки, `rotate` с задержкой 0,25 с. `transform` из открытых правил
   убрать.
2. **`--second`.** `transition: opacity 0.25s cubic-bezier(0, 0, 0, 1);` в базовом правиле; открытое —
   `opacity: 0` как сейчас.
3. **Средняя полоска — без задержки в обе стороны**, как у библиотеки.
4. **`prefers-reduced-motion: reduce`:** у всех трёх полосок `transition: none`.
5. **Замер анимации.** В браузере на 390 px: клик, `document.getAnimations()`, пауза, `currentTime`
   0 / 125 / 250 / 375 / 500 мс — `translate`, `rotate`, `opacity` каждой полоски, отдельно на
   открытии и закрытии. Числа — в отчёт.
6. **Геометрия в конце:** крестик — линии ±45°, пересечение в центре (T13 давал центры 40,5 = 40,5);
   кнопка 48 × 48, высота хедера 81 px.
7. **Проверка в браузере:** 320, 390, 767 — открытие/закрытие кликом, Tab и Enter; с
   `prefers-reduced-motion: reduce` — мгновенно.
