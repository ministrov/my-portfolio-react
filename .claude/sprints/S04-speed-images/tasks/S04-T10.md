# S04-T10 — Карточка: 2 px и пустой блок ссылок

**Исполнитель:** Junior · **Оценка:** 1 SP · **Статус:** To do
**Зависит от:** T06 · **Ветка:** `sprint/S04-speed-images`

## Контекст

Два мелких дефекта карточки проекта из карточки S01-T09, переживших спринт. Делаются после T06: рамка
карточки к тому моменту уже новая, замеры — на ней.

## Что сейчас (проверить замером на старте)

1. **Кадр на 2 px шире колонки.** `src/components/projectCard/style.css:25–31` — у `.project-card__image`
   есть `border: 1px solid` и нет `box-sizing: border-box`. В двухколоночной карточке (≥ 1275 px) кадр
   занимает на 2 px больше половины. Глобального `box-sizing` в проекте нет — проверено: он есть только
   у отдельных элементов.
2. **Пустой блок ссылок.** `src/components/projectCard/ProjectCard.jsx:191` — `<div class="project-card__links">`
   рендерится всегда, даже когда ссылок нет (у Ratingus нет ни `demoLink`, ни `gitHubLink`). Блок пустой,
   но это элемент flex-контейнера `.project-card__tools`: на ≤ 580 px у контейнера `gap: 1rem` — под
   карточкой остаётся лишние 16 px пустоты.

## Что сделать (направление)

1. **2 px:** причина — рамка вне ширины. Нужно, чтобы рамка входила в ширину элемента; проверь, как в
   проекте это решено у соседних блоков с рамками (`grep box-sizing` по `src/`).
2. **Пустой блок:** лид на старте выбирает одно из двух и объясняет:
   - рендерить блок только когда есть хотя бы одна ссылка (правка JSX);
   - скрыть пустой блок правилом `:empty` в CSS.
3. Пересказ в чат до кода: что меняешь и по какому признаку поймёшь, что готово.

## Критерии приёмки

- [ ] На 1280 и 1440 кадр и текстовая колонка одной ширины (расхождение ≤ 1 px — замер в отчёте).

      отступы прежние.
- [ ] `npm run lint`, `npm run test:run`, `npm run build` — без ошибок.
- [ ] Правки только в двух файлах карточки.

## Новое для тебя

`box-sizing: border-box`: что именно входит в ширину элемента — содержимое, padding, рамка — и почему
ширина «на 2 px больше» появляется незаметно.
