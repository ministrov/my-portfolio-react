# S04-T05 — LCP: элемент и повторный замер

**Исполнитель:** Лид · **Оценка:** 2 SP · **Статус:** To do
**Зависит от:** T03, T04 · **Ветка:** `sprint/S04-speed-images`

## Контекст

LCP — узкое место с S01: 3,8 с на `/about` и 4,4 с на главной при норме 2,5 с. T02 назвал LCP-элемент
на базе, T03 убрал сдвиг шрифтов, T04 разгрузил главный чанк. Эта задача — проверить, сдвинулся ли LCP,
и точечно взяться за элемент, который его держит.

## Что сделать

1. Снять LCP после T03 и T04 в тех же условиях, что T02 (3 прогона, медиана), на `/` и `/about`, RU и EN.
2. Сравнить элемент LCP с базой T02. Возможные рычаги — по факту элемента:
   - текст → preload нужного начертания уже сделан в T03; проверить момент подмены шрифта;
   - изображение (герой, фото автора) → `fetchpriority="high"`, размеры под фактическую ширину,
     предзагрузка в `index.html` или из шапки страницы;
   - элемент ниже первого экрана → проверить, не вызван ли LCP смещением/ленивой загрузкой.
3. Повторный замер и запись цифр в журнал `plan.md`.

## Критерии приёмки

- [ ] LCP `/about` ≤ 3,0 с и `/` ≤ 3,5 с — медиана трёх прогонов; недостижение — цифры и причина
      в `CHANGELOG.md`.
- [ ] Остальные метрики не хуже T02: CLS ≤ 0,1, FCP, TBT.
- [ ] Правки LCP-элемента не меняют вид: визуальная проверка пользователем первого экрана `/` и `/about`.
- [ ] `npm run lint`, `npm run test:run`, `npm run build` — без ошибок.

## Затрагиваемые файлы

  `src/pages/AboutPage.jsx` и т. п.
