# База S04 — скорость, LCP-элемент и высоты страниц

Замер «до» для всего спринта: T03–T05 доказывают ускорение относительно этих цифр, T06, T07, T10–T12
сверяют вёрстку карточек. Снято на коде боевого сайта, до любых правок, в условиях S03-T01.
Порог приёмки для высот — **±2 px**; повторный проход на той же сборке дал расхождение **0 px**.

Высота окна зафиксирована сознательно: герой главной на мобильных занимает весь экран, поэтому высота
страницы зависит от высоты окна. Сравнивать можно только замеры с теми же окнами.

## Что измеряется

| Поле            | Как                                                                 |
| --------------- | ------------------------------------------------------------------- |
| Высота страницы | `document.documentElement.scrollHeight`                             |
| Верх подвала    | `.main-footer`: сумма `offsetTop` по цепочке `offsetParent`         |
| Прокрутка вбок  | `scrollWidth − clientWidth` у `<html>`; 0 — прокрутки нет           |
| Герой           | `.hero` на `/`, `offsetHeight`                                      |
| Карточка        | первая `.project-card` на `/projects`, `offsetWidth × offsetHeight` |

`offset*` не учитывают `transform`, поэтому анимации появления (`whileInView`, сдвиг по `y`) замер не
искажают. Элемента нет на странице — в таблице «—».

## Сценарий: как повторить

1. Сборка: `npm run build`, затем `node node_modules/vite/bin/vite.js preview --port 4173 --strictPort`
   (в фоне).
2. Замер страниц — в Claude Code, инструмент Playwright MCP `browser_run_code_unsafe`, параметр
   `code` — скрипт ниже. Один вызов — одна страница: меняется только `PATH`, значения — `/` или
   `/projects`. Если вызов завис, не повторять: записать «не проверено» и разобраться.
3. Сравнить с таблицами выше. Допуск — ±2 px. Ширины, высоты окон и флаги контекста не менять, иначе
   цифры несравнимы. Скрипт возвращает версию браузера; если она не 157.0.8103.80, сначала переснять
   базу: новый Chrome сам может сдвинуть метрики текста, и это не регресс.
4. Lighthouse — в Git Bash, при закрытом браузере Playwright, прогоны строго по очереди:

   ```bash
   for i in 1 2 3; do
     npx -y lighthouse@13.5.0 "http://localhost:4173/?lang=ru" \
       --only-categories=performance \
       --chrome-flags="--headless=new --incognito" \
       --output=json --output-path="lh-home-ru-$i.json" --quiet
   done
   ```

   Для остальных — тот же цикл с `/` `?lang=en`, `/about` RU и EN, `/projects?lang=ru`. Медиана — по
   каждой метрике отдельно. JSON-отчёты в репозиторий не кладутся: они по 0,7 МБ, 15 файлов — 8,4 МБ;
   в файле выше — нужные выдержки.

5. Остановить `vite preview`.

Скрипт: для каждой комбинации открыть страницу в новом контексте, дождаться сети и шрифтов, пройти
страницу до низа шагами по 0,8 экрана (так догружаются картинки и срабатывают анимации
`whileInView`), вернуться наверх, подождать 1,5 с и снять `scrollHeight`, верх подвала, прокрутку
вбок, высоту героя и размер карточки.

```js
async (page) => {
  const PATH = '/';
  const BASE = 'http://localhost:4173';
  const SIZES = [
    { w: 320, h: 568, touch: true },
    { w: 375, h: 667, touch: true },
    { w: 768, h: 1024, touch: true },
    { w: 1024, h: 768, touch: true },
    { w: 1280, h: 900, touch: false },
    { w: 1440, h: 900, touch: false },
  ];
  const browser = page.context().browser();
  const rows = [];
  for (const lang of ['ru', 'en']) {
    for (const s of SIZES) {
      const ctx = await browser.newContext({
        viewport: { width: s.w, height: s.h },
        deviceScaleFactor: 1,
        isMobile: s.touch,
        hasTouch: s.touch,
      });
      try {
        const p = await ctx.newPage();
        p.setDefaultTimeout(20000);
        await p.goto(`${BASE}${PATH}?lang=${lang}`, {
          waitUntil: 'networkidle',
        });
        await p.waitForSelector('.main-footer');
        const row = await p.evaluate(async () => {
          const wait = (ms) => new Promise((r) => setTimeout(r, ms));
          const de = document.documentElement;
          await document.fonts.ready;
          const step = Math.round(innerHeight * 0.8);
          for (let y = 0; y < de.scrollHeight; y += step) {
            scrollTo(0, y);
            await wait(100);
          }
          scrollTo(0, de.scrollHeight);
          await wait(300);
          await Promise.race([
            Promise.all(
              [...document.images].map((img) => img.decode().catch(() => null))
            ),
            wait(3000),
          ]);
          scrollTo(0, 0);
          await wait(1500);
          const absTop = (el) => {
            let t = 0;
            for (let n = el; n; n = n.offsetParent) t += n.offsetTop;
            return t;
          };
          const q = (sel) => document.querySelector(sel);
          return {
            page: de.scrollHeight,
            footer: q('.main-footer') ? absTop(q('.main-footer')) : '—',
            hscroll: de.scrollWidth - de.clientWidth,
            hero: q('.hero') ? q('.hero').offsetHeight : '—',
            card: q('.project-card')
              ? `${q('.project-card').offsetWidth}×${q('.project-card').offsetHeight}`
              : '—',
          };
        });
        rows.push({ lang, w: s.w, ...row });
      } finally {
        await ctx.close();
      }
    }
  }
  return JSON.stringify({ path: PATH, ua: browser.version(), rows });
};
```

Скрипт передаётся без точки с запятой в конце: инструмент оборачивает его в `await (…)(page)`, и `;`
после функции даёт SyntaxError.
