## Вопросы junior'у

1. Что вернёт `t('aboutEducation.items')` без опции и почему без проверки на массив упала бы вся
   страница, а не только раздел? — **Ответ junior'а:** «`map` проходился бы по строке, а не по
   массиву»; что React делает с ошибкой отрисовки — не знает. **Разобрали:** у строки нет `.map`,
   вызов бросает `TypeError` прямо во время отрисовки; React поднимает ошибку до ближайшего
   Error boundary, а в приложении их нет — React снимает всё дерево, страница становится белой.
2. Почему здесь ключом можно взять индекс и когда было бы нельзя? — **Ответ junior'а:** нельзя,
   когда элементы добавляются или удаляются, — чтобы React правильно отслеживал изменения. Верно;
   **дополнили:** ещё сортировка и фильтр (фильтр на /projects) — тогда состояние и DOM одного
   элемента достаются другому, стоящему на том же месте.
