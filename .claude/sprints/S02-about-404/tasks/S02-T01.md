# S02-T01 — Статус ответа сервера и база замеров /about

**Исполнитель:** Лид · **Оценка:** 1 SP · **Статус:** In progress
**Зависит от:** — · **Ветка:** `sprint/S02-about-404`

## Контекст

Блок 01 ТЗ, гайд S02-T01. Из среды автора ТЗ сайт был недоступен — статус ответа для
несуществующего адреса и для /about не установлен. «Мягкий 404» (200 на любой адрес) не ломает
страницу, но если /about при прямом заходе отвечает 404 — прямые ссылки сломаны, это блокер.
Плюс база дня 1 для метрики «Lighthouse mobile /about, Accessibility — не ниже исходного».

## Что сделать

- `curl -sI https://antoshkindev.ru/no-such-page` и `https://antoshkindev.ru/about` — первая
  строка ответа; результат — в журнал `plan.md`.
- `/about` → 404 — сразу сообщить пользователю (блокер). `/no-such-page` → 200 — записать «мягкий
  404», решение по хостингу — за пользователем (вне репозитория).
- Lighthouse mobile на `/about?lang=ru`: прогоняет пользователь, как в S01 (сборка, `vite
preview`, 3 прогона, медиана); лид записывает в `baseline.md` этого спринта.

## Критерии приёмки

- [ ] `baseline.md`: Performance и Accessibility /about до правок, условия замера.
