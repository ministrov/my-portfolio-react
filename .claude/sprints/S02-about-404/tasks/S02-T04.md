# S02-T04 — Видимый h1 на /about

**Исполнитель:** Junior · **Оценка:** 1 SP · **Статус:** Done
**Зависит от:** — · **Ветка:** `sprint/S02-about-404` · **Старт с коммита:** `116dc935`

## Цель

У каждой страницы один главный заголовок — **h1**. По нему поисковик и программа чтения с экрана
понимают, о чём страница. На /about главным должен стать видимый заголовок «Немного обо мне».

## Что сейчас

На /about два заголовка:

| Заголовок            | Где в коде                           | Уровень | Видно на экране               |
| -------------------- | ------------------------------------ | ------- | ----------------------------- |
| «Страница об авторе» | `src/pages/AboutPage.jsx:86`         | h1      | нет — класс `visually-hidden` |
| «Немного обо мне»    | `src/sections/about/About.jsx:58–62` | h2      | да                            |

Нужно: «Немного обо мне» — h1, спрятанного заголовка нет.

## Почему нельзя просто поставить h1 в `About.jsx`

Секция `About` стоит на **двух** страницах: на главной (`src/pages/HomePage.jsx`) и на /about. На
главной уже есть свой h1 — в первом экране. Если жёстко прописать h1 в секции, на главной станет
два h1. Поэтому секция должна уметь быть «h1 на /about, h2 на главной» — для этого проп со
значением по умолчанию.

## Шаги

Номера строк — на момент старта (`116dc935`).

1. **Заголовок уже умеет менять уровень.** Компонент `Heading` принимает проп `level`; по умолчанию
   он равен 2 — `src/components/heading/Heading.jsx:16`. Передашь 1 — получится h1.
2. **`src/sections/about/About.jsx:30`.** Здесь секция принимает пропы `link`, `button`, `border`,
   у каждого значение по умолчанию (`= false`). Добавь рядом свой проп для уровня заголовка —
   например, `headingLevel` — со значением по умолчанию 2. Передай его в `Heading` на строках
   58–62.
3. **`src/pages/AboutPage.jsx`:**
   - строка 88, `<About border />` — передай туда свой новый проп со значением 1;
   - удали строки 85–86 — спрятанный h1 и комментарий над ним.
4. **`src/pages/HomePage.jsx` не трогай.** Там проп не передаётся — сработает значение по
   умолчанию 2, всё останется как было.
5. **Словари.** Ключ `pages.about.title` был нужен только удалённому h1. В
   `src/utils/i18n/locales/ru/ru.json` и `en/en.json`, строки 24–26, удали блок `"about": { … }`
   внутри `"pages"`. Блок `"projects"` рядом **оставь** — его использует `ProjectsPage.jsx`. Следи за
   запятыми: JSON не прощает ни лишнюю, ни пропущенную.

## Как проверить, что готово

- Открой /about. В консоли DevTools набери `document.querySelectorAll('h1')` — ровно один элемент,
  и это «Немного обо мне» (в EN — английский вариант).
- На главной во вкладке Elements у «Немного обо мне» — тег `h2`.
- Внешне на обеих страницах ничего не изменилось.
- `npm run lint`, `npm run test:run`, `npm run build` — без ошибок.
- Готово — `/team-lead review S02-T04`. Коммитить не нужно.
