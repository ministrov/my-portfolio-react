# S02-T04 — Видимый h1 на /about

**Исполнитель:** Junior · **Оценка:** 1 SP · **Статус:** In progress
**Зависит от:** — · **Ветка:** `sprint/S02-about-404`

## Что нужно сделать

У каждой страницы должен быть один главный заголовок — **h1**. По нему поисковик и программа
чтения с экрана понимают, о чём страница. Сейчас на «Обо мне» h1 спрятан (его не видно), а видимый
заголовок «Немного обо мне» — второго уровня, **h2**.

Нужно: на /about главным (h1) стал видимый «Немного обо мне», а спрятанный h1 исчез. На
**главной** та же секция «Обо мне» остаётся с h2 — там главный заголовок другой.

## Как проверить, что готово

- Открой /about, в консоли DevTools набери `document.querySelectorAll('h1')` — ровно один элемент,
  и это «Немного обо мне» (в EN — английский вариант).
- На главной во вкладке Elements у «Немного обо мне» — `h2`.
- Внешне на обеих страницах ничего не изменилось.
- Проверки: `npm run lint`, `npm run test:run`, `npm run build` — без ошибок.

## Новое для тебя

**Проп со значением по умолчанию.** Компонент по умолчанию ведёт себя как раньше, а одна страница
передаёт ему другое значение — так одна и та же секция бывает h1 на одной странице и h2 на другой.

## Подсказки (по желанию)

- Компонент заголовка уже умеет менять уровень — прочитай его описание (JSDoc) в
  `components/heading/Heading.jsx`.
- Секция «Обо мне» — `sections/about/About.jsx`. Посмотри, как она уже получает пропы `link`,
  `button` и `border` со значениями по умолчанию, — сделай так же.
- Секция стоит на двух страницах: `pages/HomePage.jsx` и `pages/AboutPage.jsx`. Менять нужно
  только одну из них.
- Текст спрятанного заголовка берётся из словаря. После правки этот ключ, скорее всего, больше не
  нужен: найди его поиском по проекту и, если он нигде больше не используется, удали из
  **обеих** локалей.
- Описание нового пропа (JSDoc) и тест делаю я.
