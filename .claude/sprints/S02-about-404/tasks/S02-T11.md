последней. У каждого заголовка лишнее «Учебное заведение:», а в «Мое» нет буквы «ё».

   (Label) — учебное заведение, заголовок — программа, описание — только у PurpleSchool.

3. Старые данные образования, старые ключи словаря и старые стили, которые больше не нужны, —
   удали.
4. Заголовок раздела: «Моё образование» (в EN без изменений).
