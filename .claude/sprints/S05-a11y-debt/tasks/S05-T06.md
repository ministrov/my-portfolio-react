# S05-T06 — Списки и озвучка: глобальный `li`, aria-лейблы на `/about`

**Исполнитель:** Мидл (`layout-engineer`) · **Оценка:** 2 SP · **Статус:** To do
**Зависит от:** T02 · **Ветка:** `sprint/S05-a11y-debt`

## Контекст

`main.css` глобально снимает маркеры у всех `li` (`list-style: none`) — в Safari с VoiceOver такой
список не объявляется списком. На `/about` два списка с почти одинаковым именем
(`about.techAriaLabel` и группы стека) — скринридер читает «список, список» без различия.

## Что сделать

1. Семантика списков: вернуть объявление списка там, где он настоящий, не ломая вид. Решение лида:
   маркеры не возвращать, но список должен объявляться — проверить, достаточно ли `list-style: ''` на
   нужных контейнерах или требуется `role="list"`; объяснить выбор в комментарии (рус.).
2. `/about`: развести доступные имена двух списков — правка ключей в `ru.json` и `en.json` (оба),
   без изменения видимого текста.
3. Тесты: у `AboutStory`/списков тестов нет — добавь проверку доступных имён, если компонент
   тестируется в проекте; при сомнении — вопрос лиду.
4. Проверка в браузере: в DevTools → Accessibility у обоих списков разные имена; списки — `list`.

## Критерии приёмки

- [ ] `ul`/`ol` сайта объявляются списком (проверка по DevTools Accessibility на `/` и `/about`).
- [ ] Видимый вид списков не изменился (скриншоты/высоты ±2 px).
- [ ] Два списка на `/about` имеют разные доступные имена; `ru.json` и `en.json` синхронны.
- [ ] `npm run lint`, `npm run test:run`, `npm run build` — без ошибок.
