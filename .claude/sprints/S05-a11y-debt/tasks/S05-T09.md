# S05-T09 — `body { min-width }` на 320: убрать прокрутку

**Исполнитель:** Лид · **Оценка:** 1 SP · **Статус:** To do
**Зависит от:** T02 · **Ветка:** `sprint/S05-a11y-debt`

## Контекст

`body { min-width: 320px }` (`src/styles/main.css:184`, правило с 2025-06-30) при классических
скроллбарах даёт горизонтальную прокрутку на экране 320 px: `clientWidth` 310, `body` — 320,
`window.scrollTo(200, 0)` оставляет `scrollX = 10` (найдено в S04-T13). В браузере пользователя с
накладными скроллбарами прокрутки нет. Кандидат проверен инъекцией: `min-width: min(320px, 100%)` —
`scrollX` 0 на 320 / 375 / 300.

## Что сделать

1. Заменить правило на `min-width: min(320px, 100%)` (или снять — решить по замеру; объяснить в
   комментарии, рус.).
2. Проверить: `scrollX` после `scrollTo(200, 0)` на 320 — 0; `body` = `clientWidth` на 300/320/375.
3. Регрессия высот всех страниц (`/`, `/about`, `/projects`, 404) на 320 и 375, RU и EN — ±2 px.
4. Проверить, что на реальной мобильной ширине (без скроллбара) ничего не изменилось.

## Критерии приёмки

- [ ] При `clientWidth` 310 прокрутка вбок невозможна: `scrollX` 0 (замер лида).
- [ ] Высоты 4 страниц на 320 и 375 в обоих языках — ±2 px.
- [ ] Видимых изменений на 375+ нет (скриншоты).
- [ ] `npm run lint`, `npm run test:run`, `npm run build` — без ошибок.
