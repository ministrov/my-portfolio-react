# S05-T16 — MIME `application/x-javascript` → `text/javascript`

**Исполнитель:** Пользователь + Лид · **Оценка:** 1 SP · **Статус:** To do
**Зависит от:** — · **Ветка:** `sprint/S05-a11y-debt`

## Контекст

Проверка выкладки S04 (27.11): nginx отдаёт JS как `application/x-javascript` — устаревший тип.
Браузеры принимают, но стандарт — `text/javascript`; некоторые инструменты (строгие CSP-аудиты,
проверки безопасности) могут ругаться.

## Что сделать

1. Проверить в панели Timeweb, можно ли задать MIME для `.js`/`.mjs` как `text/javascript`.
2. Если панель не умеет — добавить `AddType text/javascript .js .mjs` в `public/.htaccess`
   (помнить про `.gitattributes` и `eol=lf` из S04-T09).
3. Проверить после распространения: `curl -sI https://antoshkindev.ru/assets/index-*.js | grep -i content-type`.
4. Записать в CHANGELOG/журнал, каким способом сделано.

## Критерии приёмки

- [ ] JS на боевом сайте отдаётся с `Content-Type: text/javascript` (или `application/javascript` при
      невозможности — с объяснением).
- [ ] Ничего не сломалось: сайт грузится, консоль без ошибок, чанки 200.
- [ ] Способ зафиксирован в журнале.
