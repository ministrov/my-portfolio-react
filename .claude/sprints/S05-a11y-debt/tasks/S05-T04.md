# S05-T04 — Фокус и движение: `nav-list`, `ButtonLink`, стрелка `CtaButton`

**Исполнитель:** Junior · **Оценка:** 2 SP · **Статус:** To do
**Зависит от:** T02 · **Ветка:** `sprint/S05-a11y-debt`

## Контекст

Три пункта бэклога (S01-T06, S01-T09, S02-T06): у ссылок десктопной навигации нет своего
`:focus-visible`; `transition: all` у `ButtonLink` анимирует и кольцо фокуса — кольцо «плывёт»;
стрелка `CtaButton` при `prefers-reduced-motion` всё равно прыгает на 3 px, потому что снят только
`transition`, а сам сдвиг остался.

## Что сделать (направление)

1. `navDesktop/style.css` — кольцо фокуса у `.nav-list__link` по образцу проекта
   (`projectCard/style.css`, кольцо `:focus-visible`), только при клавиатуре.
2. `buttonLink/style.css` — `transition: all` заменить перечислением свойств, которые действительно
   анимируются; кольцо фокуса в переход не входит.
3. `ctaButton/` — при `prefers-reduced-motion: reduce` сдвиг стрелки не должен срабатывать вовсе
   (не только без плавности). Проверь, где задан сдвиг, и отключи его в reduced-мotion.
4. Проверка в браузере: Tab по навигации 1280 — кольца кобальтовые, при клике не появляются;
   `transition` у `ButtonLink` — список свойств; reduced motion — наведение на `CtaButton` не двигает
   стрелку.

## Критерии приёмки

- [ ] Tab по десктопной навигации: видимое кобальтовое кольцо; мышью кольца нет.
- [ ] `getComputedStyle(buttonLink).transitionProperty` — не `all`.
- [ ] При эмуляции `prefers-reduced-motion: reduce` стрелка `CtaButton` не смещается (замер до/после
      наведения).
- [ ] `npm run lint`, `npm run test:run`, `npm run build` — без ошибок.
- [ ] Скриншоты/значения в отчёте.
