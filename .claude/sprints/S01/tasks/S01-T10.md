# S01-T10 — Карточка проекта: сворачивание описания

**Исполнитель:** Лид · **Оценка:** 2 SP · **Статус:** Blocked — нет референса `images/04-project-card.png`
**Зависит от:** S01-T09 · **Ветка:** `sprint/S01`

## Контекст

Блок 04 ТЗ, шаг 3: описание — 6–13 строк на телефоне. На ≤ 1024 px оно сворачивается до трёх
строк; «Читать полностью» есть только там, где текст действительно обрезан.

## Что сделать

- Модификатор `.project-card__info-desc--clamped` (line-clamp: 3) внутри `@media (max-width: 1024px)`.
- `isExpanded` в состоянии, `id` описания через `useId()`; кнопка с `aria-expanded` и
  `aria-controls`, подписи `projectCard.readMore` / `projectCard.readLess`, высота 44 px.
- Кнопка показывается только при реальном переполнении: замер `scrollHeight > clientHeight` +
  `ResizeObserver` (как в `useCharWidths`); на ≥ 1025 px скрыта, текст полный.
- Ключи в `ru.json` и `en.json`.
- Тест `ProjectCard.test.jsx`: мета-строка, `aria-expanded` и подпись меняются, без `gitHubLink` —
  одна ссылка (переполнение подменить через `Object.defineProperty`).

## Критерии приёмки

- [ ] На ≤ 1024 px описание свёрнуто до трёх строк; кнопка есть только у длинных описаний.
- [ ] Кнопка меняет `aria-expanded` и подпись; у самого короткого описания кнопки нет.
- [ ] Карточка «Вам Вода» на 390 px ≤ 820 px; `/projects` на 360 px ≤ 8 000 px.
- [ ] Definition of Done: lint, test:run, build, обе локали, JSDoc на русском, `CHANGELOG.md`.
