# S01-T07 — `ToggleLang` → сегмент RU/EN

**Исполнитель:** Junior · **Оценка:** 2 SP · **Статус:** To do
**Зависит от:** — · **Ветка:** `sprint/S01`

## Контекст

Блок 03 ТЗ, шаг 4. Сейчас переключатель — кнопка «Ру» высотой 34 px, и она показывает **текущий**
язык, а не тот, на который переключит: посетитель не понимает, что произойдёт по нажатию.
Решение — две кнопки RU и EN, текущая отмечена.

## Что сделать

- `ToggleLang` становится группой из двух кнопок RU и EN; текущий язык отмечен.
- Клик по неактивной кнопке переключает язык, по активной — ничего не делает.
- Высота группы 44 px на ≤ 767 px и 40 px в хедере; фон Frost, активный сегмент — белый с тенью
  в тоне Cobalt Shadow (ТЗ, блок 03, шаг 4; `DESIGN.md` → Colors).
- Тест `ToggleLang.test.jsx`.

## Критерии приёмки

- [ ] Две кнопки RU/EN в группе с доступным именем; текущий язык отмечен через `aria-pressed`.
- [ ] Клик по активной кнопке не вызывает переключение; по неактивной — вызывает.
- [ ] Высота ≥ 44 px на телефоне; в хедере и в мобильном меню выглядит аккуратно.
- [ ] **Внешний API не меняется:** default-экспорт и проп `className` работают как раньше — компонент
      рендерят `Header` и `MobileMenu`, их трогать не нужно.
- [ ] `?lang=` и localStorage работают как раньше, `src/utils/lang.test.js` зелёный.
- [ ] Тест: `aria-pressed` у текущего языка; клик по активной кнопке не переключает язык.
- [ ] Definition of Done: lint, test:run, build, обе локали, JSDoc на русском, `CHANGELOG.md`.
