# S01-T07 — `ToggleLang` → сегмент RU/EN

**Исполнитель:** Junior · **Оценка:** 2 SP · **Статус:** In progress
**Зависит от:** — · **Ветка:** `sprint/S01`

## Контекст

Блок 03 ТЗ, шаг 4. Сейчас переключатель — кнопка «Ру» высотой 34 px, и она показывает **текущий**
язык, а не тот, на который переключит: посетитель не понимает, что произойдёт по нажатию.
Решение — две кнопки RU и EN, текущая отмечена.

## Что сделать

- `ToggleLang` становится группой из двух кнопок RU и EN; текущий язык отмечен.
- Клик по неактивной кнопке переключает язык, по активной — ничего не делает.
- Высота группы 44 px на ≤ 767 px и 40 px в хедере; фон Frost, активный сегмент — белый с тенью
  в тоне Cobalt Shadow (ТЗ, блок 03, шаг 4; `DESIGN.md` → Colors).
- Сегмент — **на всех ширинах**: в хедере от 768 px, включая десктоп, и в мобильном меню. Отдельного
  десктопного варианта нет (решение пользователя 2026-10-21, см. «Решения лида»).
- Тест `ToggleLang.test.jsx`.
- Поправить поиск переключателя в `MobileMenu.test.jsx` — после твоей правки он перестанет
  находить одиночную кнопку.

## Решения лида (уже приняты — не выбирать заново)

- **Разметка — паттерн toggle button из WAI-ARIA APG:** группа (`role="group"`) из двух нативных
  `<button>`, состояние — `aria-pressed`. Образец `aria-pressed` в проекте —
  `components/filterButton/`.
- **Ширины:** один вид и одно поведение везде, без ветки по медиазапросу. ТЗ противоречит само себе
  (шаг 4 — «40 px в хедере», критерий — «на ≥ 1025 px хедер как раньше»); пользователь выбрал
  сегмент на всех ширинах. Это осознанное исключение из «десктоп не меняется», как цвета карточек
  проектов в блоке 04: проблема «показывает текущий язык, а не целевой» не зависит от устройства.
- **Доступные имена:** у группы — существующий ключ `toggleLang.ariaLabel`; у кнопок — их видимый
  текст RU и EN, без отдельного `aria-label`.
- **Способ теста:** рендер внутри `LanguageContext.Provider` с тестовым значением
  `{ lang, toggleLang }`, где `toggleLang` — шпион (`vi.fn()`). Так тест проверяет ровно контракт
  компонента — «вызвал ли он переключение» — без роутера и `localStorage`.
  - Объект контекста `LanguageContext` — из `context/LanguageProvider.jsx`; хук, который вызывает
    компонент, — из `hooks/useLanguage.jsx`. Это два разных `useLanguage`, не перепутай.
  - Хук вызывает `i18n.changeLanguage`, поэтому в тесте нужна инициализация i18next — посмотри
    первые строки `MobileMenu.test.jsx`.
  - Образцы тестов: `navMobile/MobileMenu.test.jsx`, `ctaButton/CtaButton.test.jsx`.

## Тест — по шагам (направление, без кода)

1. **Прочитай** (около часа): Testing Library → About Queries (почему `getByRole` первым);
   Vitest → `vi.fn` (функция-шпион: запоминает, сколько раз и с чем её вызвали); React →
   Passing Data Deeply with Context (что делает `Provider` — передаёт значение всему, что внутри).
2. **Начало файла** — как в `MobileMenu.test.jsx`: импорты из `vitest` и `@testing-library/react`,
   строка 10 — инициализация i18next. Роутер не нужен: в `ToggleLang` нет ссылок.
3. **Помощник рендера** — как `renderMenu` (`MobileMenu.test.jsx:31`): принимает `lang`, создаёт
   шпион `toggleLang`, рендерит `ToggleLang` внутри `LanguageContext.Provider` со значением
   `{ lang, toggleLang }` и возвращает шпиона.
4. **Тест 1 — разметка:** группа находится по роли и имени (текст — в `ru.json`, ключ
   `toggleLang.ariaLabel`); у кнопки текущего языка `aria-pressed` — `true`, у второй — `false`.
   Матчер `toHaveAttribute` — пример в `MobileMenu.test.jsx:86`.
5. **Тест 2 — клик по неактивной:** шпион вызван один раз — как `CtaButton.test.jsx:85–91`.
6. **Тест 3 — клик по активной:** шпион не вызван — `not.toHaveBeenCalled()`, как
   `MobileMenu.test.jsx:127`. Пока на активной кнопке стоит `disabled`, этот тест проходит
   **случайно**: клик по `disabled` не доходит до обработчика. Сначала убери `disabled`, потом
   прогони тест.
7. **Проверь, что тест умеет падать:** временно убери условие `if (!isActive)` — тест 3 должен
   покраснеть. Верни условие. Зелёный тест, который не может покраснеть, ничего не проверяет.
8. **Запуск:** `npm test -- ToggleLang` (перезапускается при сохранении файла).
