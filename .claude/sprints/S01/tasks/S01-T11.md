## Контекст

Блок 05 ТЗ. На 360 px семь карточек по ~190 px ради одной строки текста — секция 1 521 px, почти
два экрана. Цель — все семь тезисов строками в одной карточке, ~620 px. Разметка уже `<ul>`/`<li>`,
меняется только CSS. Референс — `images/05-advantages.png`.

## Что сделать

- На ≤ 1024 px: список-карточка, строки «иконка 40 px + текст» с волосяной линией между ними;
  569–1024 px — две колонки строк, ≤ 568 px — одна.
- Подъём карточки при наведении — только для мыши и только на десктопе; на таче после тапа строка
  не должна оставаться приподнятой.
- Десктопная бенто-сетка (≥ 1025 px) — без изменений.

## Критерии приёмки

## Подсказки

- **Посмотри в проекте:** весь `sections/advantages/style.css` — особенно правила с
  `:nth-child(...)` и то, как существующий `@media (max-width: 1024px)` их уже перебивает. Как
  выглядит волосяная линия у FAQ (`sections/faq/`) — референс говорит «тот же язык».
- **Подход:** в ТЗ (блок 05, гайд) значения свойств уже расписаны почти готовым CSS. Не копируй
  вслепую — для каждого свойства ответь себе «зачем оно здесь»; на ревью спрошу про специфичность
  и про ховер.
- **Подумай:** ТЗ предлагает обернуть ховер в `(hover: hover) and (min-width: 1025px)`. Сверь это с
  Desktop-First Rule в `DESIGN.md`. Можно ли добиться того же без `min-width`? Реши и обоснуй.
- **Документация:** MDN → Specificity; MDN → `@media (hover)`; web.dev → Learn CSS → Grid.

## Новое для тебя в этой задаче

Перестройка раскладки на брейкпоинте поверх существующих правил: специфичность (`:nth-child`),
медиа-функции ввода (`hover`) и то, как не сломать десктоп, меняя мобильный вид.
