## Раунд 1 — Request changes

### Что хорошо

- Правила высоты и подсказки ограничены ≤ 1024 px, хотя гайд ТЗ клал их в базовый `.hero`:
  десктоп остался прежним (на 1280 — 928 px, как до задачи). Отклонение от гайда обосновано
  целью спринта и замерено.
- `AvailabilityBadge` — свой BEM-блок, внешняя геометрия (`align-self`) — классом-миксом
  родителя: бейдж не знает, где стоит, и не помешает T12.
- `.cta-button--outline`: `min-height` вместо `height` (зум), hover только под
  `@media (hover: hover)`, отклик на касание через `:active`.
- Тесты по делу: класс варианта, порядок колбэка и скролла, обе локали бейджа, модификатор.
- Подробный отчёт с замерами и честно отмеченными частичными критериями.

### 🔴 Блокирующие

- `src/sections/hero/Hero.jsx` — на таче подзаголовок шифровался заново при возврате к герою:
  `useScrambleText` перезапускает расшифровку при каждом включении `active`
  (`isSubtitleInView`). Критерий ТЗ — «расшифровывается один раз». Правка вне «одной строки
  `loop`» согласована с пользователем.
- `src/sections/hero/style.css` (≤ 475 px) — `width: min(300px, 100%)` у колонки оживило старое
  `.hero__btn-frame { width: 100% }`: spotlight 257 → 304 px, текст прижат влево. ТЗ: spotlight
  «не входит». Решение лида — `fit-content` на всех ≤ 767 px.
- `DESIGN.md` — DoD требует абзац о новом варианте кнопки и об изменении поведения расшифровки.
  Файл вне карточки — правка согласована с пользователем.

### 🟡 Желательно

- `.hero__secondary-cta { display: none }` побеждал `.cta-button` только порядком `<link>`
  CSS-чанков в сборке — при переразложении чанков вторая кнопка вылезла бы на десктопе, и ни один
  тест этого не поймал бы. Поднять специфичность через родителя.

### Решения лида по открытым вопросам

- Бейдж на десктопе — не показывать: цель спринта — десктоп ≥ 1025 px не меняется.
- 768–992 px: «Обсудить проект» только в бургере до T06 — так было и раньше, не регрессия.
- Находки хука дизайна в `hero/style.css` (`border-radius: 18px`, `font-size` 15px / 1.9rem /
  1.8rem / 0.875rem, градиентный текст заголовка) — были до T03 и относятся к заголовку и
  spotlight, которые ТЗ не трогает. Не подавлены; кандидаты в S02.
