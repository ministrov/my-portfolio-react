## Замечания

### 🔴 Блокирующие (без них не принимаем)

- `.claude/sprints/S01/baseline.md:10-11, 13` — заглушки `‹версия›` (Chrome, Lighthouse) и
  `‹hash›`. Критерий 2 требует версию Chrome. **Почему:** Lighthouse меняет формулу оценки между
  версиями, Chrome обновится через неделю-две — без версий в регрессии не отличить влияние наших
  правок от нового Lighthouse; без хеша неизвестно, какой код мерили. **Куда смотреть:** строка с
  версиями внизу отчёта Lighthouse; хеш — `git log` (в `src` с момента сборки изменений нет).
- `.claude/sprints/S01/baseline.md:14-15` — один прогон. **Почему:** цель ТЗ — Performance «не
  ниже исходного» (`brief.md:38`), в регрессии — «не ниже замера дня 1» (`brief.md:629`). Балл
  одной и той же сборки гуляет на несколько пунктов от прогона к прогону (фоновая нагрузка CPU,
  вкладки, симулированный троттлинг): случайно удачные 74 в день 1 сделают честные 70 после T03
  «регрессией», и наоборот. **Куда смотреть:** developer.chrome.com → Lighthouse → вариативность
  результатов; GitHub `GoogleChrome/lighthouse` → `docs/variability.md`. Выбрать число прогонов
  и правило выбора значения, записать обоснование.
- `.claude/sprints/S01/baseline/main-page-*.png` — главная обрезана на заголовке «Часто
  задаваемые вопросы»: нет FAQ, контактов, футера. **Почему:** файлы 2560×16384 и 2880×16384 —
  снято с DPR 2, а Chrome не делает скриншот выше 16384 px, поэтому влезают только первые
  8192 CSS-px страницы. **Куда смотреть:** Device Toolbar → меню ⋮ → «Add device pixel ratio».
  Заодно файлы станут примерно вчетверо легче: сейчас 4 PNG — 31 МБ, навсегда в истории git
  (весь репозиторий — 80 МБ).
- `.claude/sprints/S01/baseline/projects-page-*.png` — у 6 из 8 карточек пустая рамка вместо
  картинки (Only, Area, Рейтингус, Личный блог, Креатекс, Mish). **Почему:** у картинок
  `loading="lazy"` (`src/components/projectCard/ProjectCard.jsx:76`) — браузер грузит их только
  у экрана, а «Capture full size screenshot» страницу не прокручивает. Регрессия сравнивает
  именно карточки проектов. **Куда смотреть:** что сделать со страницей перед снимком, чтобы
  картинки успели загрузиться; результат проверить глазами до коммита.

Ловушки из двух последних пунктов карточка не называла — недоработка подсказок лида. Но снимок
без FAQ или без картинок проектов не выполняет свою работу, поэтому замечания блокирующие.
