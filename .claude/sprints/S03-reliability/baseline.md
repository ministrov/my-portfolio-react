# База регрессии S03

Замер «до» для всего спринта. Почти все задачи S03 — рефакторинг, после которого вид сайта не
должен измениться. Этот файл — то, с чем сравнивают: T04, T09, T12, T14, T16, T19 и итоговая
регрессия на демо. Порог приёмки из ТЗ — **±2 px**. Повтор на той же сборке даёт расхождение 0 px,
так что любая ненулевая разница — уже повод посмотреть, что изменилось.

## Что измеряется

| Поле             | Как                                                                                                        |
| ---------------- | ---------------------------------------------------------------------------------------------------------- |
| Высота страницы  | `document.documentElement.scrollHeight`                                                                    |
| Верх подвала     | `.main-footer`: сумма `offsetTop` по цепочке `offsetParent`                                                |
| Прокрутка вбок   | `scrollWidth − clientWidth` у `<html>`; 0 — прокрутки нет                                                  |
| Кнопка резюме    | `.hero__btn`, `offsetWidth × offsetHeight`                                                                 |
| Поле формы       | первое `.contact-form__input`, `offsetWidth × offsetHeight`                                                |
| Форма целиком    | `.contact-form`, `offsetHeight` — для T09                                                                  |
| Кнопка «наверх»  | `.scroll-to`, `offsetWidth × offsetHeight` — после прокрутки, при которой кнопка появляется (см. сценарий) |
| Карточка проекта | первая `.project-card` на `/projects`, `offsetWidth × offsetHeight`                                        |
| Герой            | `.hero` на `/`, `offsetHeight` — для T12, T16                                                              |
| IDE-карточка     | `.author-card` на `/about`, `offsetHeight` — для T16                                                       |

`offset*` не учитывают `transform`, поэтому анимации появления (`whileInView`, сдвиг по `y`) замер не
искажают. Элемента нет на странице — в таблице «—».

## Сценарий: как повторить

1. Сборка: `npm run build`, затем `npx vite preview --port 4173 --strictPort` (в фоне).
2. Замер страниц — в Claude Code, инструмент Playwright MCP `browser_run_code_unsafe`, параметр
   `code` — скрипт ниже. Один вызов — одна страница: меняется только `PATH`, значения — `/`, `/about`,
   `/projects`, `/no-such-page`. Вызов идёт около минуты. Если завис, не повторять: записать
   «не проверено» и разобраться.
3. Сравнить с таблицами выше. Допуск — ±2 px. Ширины, высоты окон и флаги контекста не менять, иначе
   цифры несравнимы. Скрипт возвращает версию браузера (`ua`). Если она не 156.0.8078.80, сначала
   переснять базу на коде `be433870`: новый Chrome сам может сдвинуть метрики текста, и это не регресс.
4. Lighthouse — в Git Bash, при закрытом браузере Playwright, прогоны строго по очереди:

   ```bash
   for i in 1 2 3; do
     npx -y lighthouse@13.5.0 "http://localhost:4173/about?lang=ru" \
       --only-categories=performance,accessibility \
       --chrome-flags="--headless=new --incognito" \
       --output=json --output-path="lh-about-$i.json" --quiet
   done
   ```

   Для главной — тот же цикл с `http://localhost:4173/?lang=ru`. Медиана — по каждой метрике
   отдельно.

5. Остановить `vite preview`.

Порядок внутри скрипта для каждой комбинации:

- открыть страницу в новом контексте и дождаться сети и шрифтов;
- прокрутить страницу до низа шагами по 0,8 экрана: так догружаются картинки и срабатывают анимации
  `whileInView`;
- вызвать кнопку «наверх». На ≤ 1024 px она появляется только при прокрутке вверх ниже двух экранов
  и прячется над формой и подвалом, поэтому скрипт встаёт на 3 экрана + 200 px и поднимается на 100.
  На 1280 px — прокрутка на 700 px: кнопка видна после 300;
- вернуться наверх, подождать 1,5 с и снять замеры.

```js
async (page) => {
  // Страница замера: '/', '/about', '/projects', '/no-such-page'
  const PATH = '/';
  const BASE = 'http://localhost:4173';
  const SIZES = [
    { w: 320, h: 568, touch: true },
    { w: 390, h: 844, touch: true },
    { w: 768, h: 1024, touch: true },
    { w: 1024, h: 768, touch: true },
    { w: 1280, h: 900, touch: false },
  ];
  const browser = page.context().browser();
  const rows = [];
  for (const lang of ['ru', 'en']) {
    for (const s of SIZES) {
      const ctx = await browser.newContext({
        viewport: { width: s.w, height: s.h },
        deviceScaleFactor: 1,
        isMobile: s.touch,
        hasTouch: s.touch,
      });
      try {
        const p = await ctx.newPage();
        p.setDefaultTimeout(20000);
        await p.goto(`${BASE}${PATH}?lang=${lang}`, {
          waitUntil: 'networkidle',
        });
        await p.waitForSelector('.main-footer');
        const row = await p.evaluate(async (touch) => {
          const wait = (ms) => new Promise((r) => setTimeout(r, ms));
          const de = document.documentElement;
          await document.fonts.ready;
          // Проход до низа: ленивые картинки и анимации whileInView
          const step = Math.round(innerHeight * 0.8);
          for (let y = 0; y < de.scrollHeight; y += step) {
            scrollTo(0, y);
            await wait(100);
          }
          scrollTo(0, de.scrollHeight);
          await wait(300);
          await Promise.race([
            Promise.all(
              [...document.images].map((img) => img.decode().catch(() => null))
            ),
            wait(3000),
          ]);
          // Кнопка «наверх»: свои правила появления на тач и на десктопе
          const maxY = de.scrollHeight - innerHeight;
          if (touch) {
            const y0 = innerHeight * 3 + 200;
            if (maxY > y0) {
              scrollTo(0, y0);
              await wait(300);
              scrollTo(0, y0 - 100);
              await wait(800);
            }
          } else if (maxY > 700) {
            scrollTo(0, 700);
            await wait(800);
          }
          const btn = document.querySelector('.scroll-to');
          const up = btn ? `${btn.offsetWidth}×${btn.offsetHeight}` : '—';
          scrollTo(0, 0);
          await wait(1500);
          const absTop = (el) => {
            let t = 0;
            for (let n = el; n; n = n.offsetParent) t += n.offsetTop;
            return t;
          };
          const q = (sel) => document.querySelector(sel);
          const size = (sel) =>
            q(sel) ? `${q(sel).offsetWidth}×${q(sel).offsetHeight}` : '—';
          const height = (sel) => (q(sel) ? q(sel).offsetHeight : '—');
          return {
            h1: (q('h1')?.textContent || '').trim().slice(0, 20),
            page: de.scrollHeight,
            footer: q('.main-footer') ? absTop(q('.main-footer')) : '—',
            hscroll: de.scrollWidth - de.clientWidth,
            hero: height('.hero'),
            author: height('.author-card'),
            form: height('.contact-form'),
            resume: size('.hero__btn'),
            input: size('.contact-form__input'),
            card: size('.project-card'),
            up,
          };
        }, s.touch);
        rows.push({ lang, w: s.w, ...row });
      } finally {
        await ctx.close();
      }
    }
  }
  return JSON.stringify({ path: PATH, ua: browser.version(), rows });
};
```

Скрипт передаётся без точки с запятой в конце: инструмент оборачивает его в `await (…)(page)`, и
`;` после функции даёт SyntaxError. Prettier при сохранении этого файла её дописывает — при
копировании убрать.
