## Контекст

Карточка проекта на ≤ 768 px показывает только верх скриншота: кадр 4:5,
`object-fit: cover`, `object-position: top` (`src/components/projectCard/style.css:454-464`). Остальные
пиксели файла скачиваются и выбрасываются.

Где какой файл используется (`src/components/projectCard/ProjectCard.jsx:99-121`, `BREAKPOINTS` в
`src/const/index.jsx` — 375 / 768):

| ≤ 375 px  | `*-mobile.webp`     | 4:5, cover сверху                             | 1,25 × ширины файла |

## Решения лида

- **Инструмент:** Pillow 13.0.0 уже установлен (`pip install`, проверено лидом:
  `features.check('webp')` — `True`). В `package.json` ничего не добавляется, npm-пакеты не ставятся.
  Скрипт обработки — во временной папке **вне репозитория** (например `%TEMP%\s03t20\`); в git
  попадают только `.webp`.
- **Кроп сверху, без изменения ширины:** оставить верх файла с запасом ≥ 15 % над видимой высотой из
  таблицы выше — запас на округления и на то, что высота кадра считается от ширины контейнера.
  Вычислить видимую высоту самому на 375, 768, 1024 и не верить таблице на слово.
- **Качество:** первый проход `quality=90, method=6`; если файл > 256 000 B — 85, затем 80. Выбранное
  качество и итоговый размер — в отчёт.
- **`vam-voda.webp` не кропится** — виден целиком (658 × 1004 / 1405 ≈ 470 px при потолке 536).
  Его только пережать до 256 000 B. Если для этого нужно качество ниже 80 или уменьшение ширины —
  остановиться и спросить лида, не решать самому.
- **`imgHeight` и `projects.js` не меняются:** атрибуты `width/height` относятся только к десктопному
  `<img>`, а десктопные файлы не кропятся — пропорции те же. Если замер покажет иное — вопрос лиду.
- **`-cover.webp` и `Showcasing` вне scope:** другой набор файлов.

## Что сделать

1. Скопировать оригиналы шести файлов во временную папку рядом со скриптом — это «до».
2. Замерить в браузере на `/projects`, сколько файла реально видно на 375, 768, 1024, 1280 (RU):
   верх карточки в кадре и сколько пикселей исходника попадает в кадр. Записать числа.
3. Снять скриншоты карточек «до» на 375, 768, 1024, 1280 (`npm run preview` на свежем порту, RU).
4. Скриптом на Pillow: кроп сверху (шаг 2) и пережать по лестнице качества (шаг 3 решений).
   Ширину не менять, формат `.webp`, RGB без альфы.
5. Проверить: каждый файл ≤ 256 000 B; ширина прежняя; кроп не тронул видимую часть.
6. Пересобрать, снять скриншоты «после» на тех же ширинах и сравнить с «до»: кадр карточки должен
   совпасть. Отдельно — высоты страницы `/projects` до и после: сдвига макета быть не должно.
7. `npm run lint`, `npm run test:run`, `npm run build`.

- [ ] Высоты страницы `/projects` до и после совпадают; `imgHeight` и `projects.js` не изменены.
