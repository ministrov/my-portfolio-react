**Исполнитель:** Junior · **Оценка:** 1 SP · **Статус:** To do

## Цель

Когда посетитель отправляет форму, его имя, email и сообщение вместе с ключом попадают в консоль браузера:
это отладочные логи, которые уехали на боевой сайт. Нужно их убрать и сделать так, чтобы новые не
проходили lint.

| Логи запроса   | `src/api/contactApi.js:45`, `63`, `76`                 |
| Логи формы     | `src/components/contactForm/useContactForm.js:136–180` |
| Настройки lint | `eslint.config.js`                                     |

## Как проверить, что готово

- В `contactApi.js` и `useContactForm.js` нет `console.log` и `console.warn`.
- `console.error` при сбое отправки остаётся, но без данных посетителя.
- Новый `console.log` в любом файле `src/` даёт ошибку `npm run lint`. Предупреждения и ошибки сбоев
  разрешены: остальные `console.warn` в проекте не ломают lint.
- Обучающие комментарии про `async` и `await` остаются, уходят только логи и подписи к ним («ШАГ 1»…).
- Отправка формы в браузере: в консоли нет данных, письмо приходит.
- Тесты из T07 зелёные, `npm run lint`, `npm run test:run`, `npm run build` — без ошибок.

Правило линтера: как договорённость «не оставляем логи» превращается в автоматическую проверку.
