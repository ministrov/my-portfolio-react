## Контекст

`App.jsx` и `HomePage.jsx` грузят 5 компонентов через `lazy`, а защиты от ошибок нет. Выкладка вручную
заменяет файлы с хешами: в уже открытой вкладке переход на новую страницу запросит файл, которого больше
нет, и посетитель увидит белый экран. То же при любой ошибке рендера.

Решение пользователя (2026-10-30): один классовый компонент как исключение из правила `CLAUDE.md`, без
новых зависимостей. Функционального API для перехвата ошибок рендера в React нет.

## Что сделать

- `components/errorBoundary/` — класс, `getDerivedStateFromError`, запасной экран: сообщение и кнопка
  перезагрузки. Текст из словарей, стили по `DESIGN.md`, поведение как у остальных кнопок.
- Обёртка вокруг маршрутов, внутри `LanguageProvider`, чтобы язык был доступен. Секции `lazy` на главной
  — своя граница или общая: решить по замеру, чтобы сбой одной секции не прятал всю главную.
- Сбой загрузки файла отличать от остальных ошибок; перезагрузка не должна зациклиться.
- Исключение записать в `CLAUDE.md`.

## Заметки по ходу

- 2026-11-05 — план одобрен пользователем. **Отступление от карточки:** граница страницы — не вокруг
  маршрутов в `App`, а в `Layout` вокруг `<Outlet/>`, с `key={pathname}`. `Suspense` стоит над всеми
  маршрутами, и граница там прятала бы шапку и подвал вопреки критерию 1. В `App` — вторая граница, для
  сбоя самой шапки или подвала. `Suspense` не переносили: это меняет вид загрузки, а вид в спринте меняют
  только T14 и T15.
- 2026-11-05 — **решение пользователя:** при сбое загрузки файла вкладка перезагружается сама один раз за
  сессию. Защита от цикла — метка `chunk-reload` в `sessionStorage`, ставится до перезагрузки. С меткой
  или без доступа к хранилищу — только экран с кнопкой. Ошибка рендера сама не перезагружает. Кнопка —
  всегда полная перезагрузка: `lazy()` запоминает неудачный импорт.
- 2026-11-05 — тексты ошибок проверены в Chrome 156 на `preview`: и обрыв (`route.abort`), и ответ 404 с
  `index.html` дают `Failed to fetch dynamically imported module: …`. Так будет на хостинге после T03.
  Firefox, Safari и CSS у Vite (`Unable to preload CSS`, есть в Vite 8.3.5) — по документированным текстам.
- 2026-11-06 — **замер для секций главной.** Только граница страницы, файл `Showcasing` заблокирован:
  пропала вся главная — героя и формы нет, страница 900 px вместо 11 411. С границами секций: на месте
