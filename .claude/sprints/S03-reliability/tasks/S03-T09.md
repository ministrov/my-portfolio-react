## Цель

В `ContactForm` два почти одинаковых куска: `input` и `textarea` отличаются двумя атрибутами, а правку
приходится делать дважды. Нужно вынести поле формы в отдельный компонент. На сайте не должно измениться
ничего.

## Как проверить, что готово

- `ContactForm.jsx` стал короче; новый компонент лежит в своей папке или рядом, по соглашениям проекта.
- `input` и `textarea` не дублируют общие атрибуты.
- Тесты T07 зелёные **без правок** — это и есть доказательство, что поведение не изменилось.
- В браузере, RU и EN: подписи, ошибки под полем, фокус на первое поле с ошибкой, блокировка при отправке,
  отправка — как было.
- Замер T01: высота формы и страницы совпадает, ±2 px.
- `npm run lint`, `npm run test:run`, `npm run build` — без ошибок.
