# S03-T07 — Тесты формы заявок: хук, API, компонент

**Исполнитель:** Лид · **Оценка:** 3 SP · **Статус:** To do
**Зависит от:** — · **Ветка:** `sprint/S03-reliability`

## Контекст

Форма — единственный способ получить заявку, и тестов на неё нет. Эта задача закрепляет текущее
поведение, чтобы T08 и T09 junior'а могли менять код с проверкой: зелёные тесты значат «ничего не
сломалось». Код формы здесь не меняется.

## Что сделать

- `contactApi.test.js`: тело запроса с ключом; успех; `success: false` и сетевая ошибка бросают
  исключение. `fetch` — мок.
- `useContactForm.test.js`: валидация по полям, `touched`, сабмит с ошибками не вызывает API и фокусирует
  первое поле; успех, ошибка, сброс.
- `ContactForm.test.jsx`: подписи и `aria-*`, связь ошибки с полем, input и textarea, баннер ошибки,
  экран успеха, RU и EN.
- Тесты не привязаны к разметке, которую T09 вынесет в отдельный компонент: ищут по роли и подписи.

## Критерии приёмки

- [ ] Тесты покрывают все статусы формы: idle, submitting, success, error.
- [ ] Проверка «может упасть»: на намеренно сломанном коде тесты красные; результат в заметках.
- [ ] Код формы не изменился.
- [ ] Definition of Done: lint, test:run, build, `CHANGELOG.md`.
