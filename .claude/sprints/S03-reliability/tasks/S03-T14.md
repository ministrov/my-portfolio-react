# S03-T14 — Искажённые скриншоты карточек на десктопе

**Исполнитель:** Верстальщик · **Оценка:** 2 SP · **Статус:** To do
**Зависит от:** T01 · **Ветка:** `sprint/S03-reliability`

## Контекст

Пункт бэклога «первым номером», с S01: на ≥ 1025 px скриншоты карточек на /projects искажены. Атрибут
`height` при `img { width: 100% }` на 1280 даёт пропорцию 0,91 вместо 0,72. Перед правкой — перепроверить
замером: задача из S01, код мог измениться.

## Что сделать

- Снять замер пропорций у всех карточек на 1025, 1280, 1440.
- Убрать искажение, не потеряв резерв места под картинку: сдвига вёрстки при загрузке быть не должно.
- Обновить `imgHeight` в данных, только если он действительно нужен.

## Критерии приёмки

- [ ] Пропорция изображения равна пропорции файла, ±0,01, у всех проектов на 1025, 1280, 1440.
- [ ] CLS на /projects не хуже базы; место под картинку зарезервировано до загрузки.
- [ ] На ≤ 1024 px карточки без изменений; замер T01 совпадает, ±2 px.
- [ ] Definition of Done: lint, test:run, build, `CHANGELOG.md`; визуальная проверка пользователя.
