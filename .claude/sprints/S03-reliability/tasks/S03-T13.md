## Как проверить, что готово

- `Up` не принимает пропсов; нужные значения — константы в файле.
- Код для случаев, которые больше невозможны, тоже удалён: например, проверка `onClick` и `icon`.
- `Up.test.jsx` зелёный без правок.
- В браузере: на 1280 кнопка появляется после 300 px прокрутки; на 390 — при прокрутке вверх, прячется над
  формой и подвалом; Esc скрывает; клик плавно ведёт наверх; при reduced motion — без плавности.
- `npm run lint`, `npm run test:run`, `npm run build` — без ошибок.
