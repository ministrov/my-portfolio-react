## Что сейчас

Текст на сайте — это **данные**: компонент сам слов не содержит, он берёт их по ключу или из массива.

| Что видно на сайте                 | Откуда берётся                     | Где лежит                                            |
| ---------------------------------- | ---------------------------------- | ---------------------------------------------------- |
| Подзаголовок героя, RU             | ключ `hero.subtitle`               | `src/utils/i18n/locales/ru/ru.json:95`               |
| Подзаголовок героя, EN             | тот же ключ, другой файл           | `src/utils/i18n/locales/en/en.json:95`               |
| `currentlyLearning` в IDE-карточке | массив `authorData.code`           | `src/const/index.jsx:142` — `['Testing', 'Node.js']` |
| «Изучаю» в «Моём стеке»            | группа `learning` в `STACK_GROUPS` | `src/const/index.jsx:122` — `['Python']`             |

Ключ `hero.subtitle` читается так: в JSON есть объект `"hero"` (строка 92), а в нём — `"subtitle"`
(строка 95). Подпись «Изучаю» / «Learning» над группой — отдельный ключ, его не трогаем.

## Почему не просто…

- **…поискать «subtitle» и править первое, что нашлось?** `"subtitle"` в словарях — четыре раза: в
  `hero` (строка 95) и в `contactForm.info` (строка 479, «Давайте обсудим ваш проект»). Нужен именно
  `hero.subtitle`. Поэтому сначала шаг 0: найти место командой и проверить, в каком объекте оно лежит.
- **…поправить только `ru.json`?** У каждого языка свой файл с одинаковыми ключами. Посетитель с
  `?lang=en` видит `en.json`, и точку там тоже нужно поставить.
- **…почему в английском «frontend developer» со строчных?** Посреди английского предложения профессия
  пишется со строчной, как «a teacher» или «a designer». С заглавных — только в заголовке или подписи.
- **…почему точка внутри кавычек?** Строка в JSON — от кавычки до кавычки, точка — часть текста. Запятая
  **после** закрывающей кавычки остаётся: она разделяет пары «ключ — значение». Без неё JSON сломается,
  словарь не загрузится, тесты упадут.
- **…трогать тест `AuthorPhoto` или `AboutCapabilities`?** Не нужно: оба строят ожидаемый текст из тех же
  массивов в `const/index.jsx`. Лид проверил: с пробной правкой — 203 из 203 без единой правки теста.
- **…писать комментарии?** Не нужно: комментарии теперь у лида.
