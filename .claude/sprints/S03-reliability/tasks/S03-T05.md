## Контекст

Репозиторий проверки сам не запускает: Definition of Done держится на памяти. PR #190 и #191 слиты без
автоматической проверки.

## Что сделать

- `.github/workflows/ci.yml`: на `pull_request` и `push` в `master` — `npm ci`, `npm run lint`,
  `npm run test:run`, `npm run build`. Версия Node — та, на которой проект работает сейчас.
- Без секретов: сборка не требует `VITE_WEB3FORMS_KEY`. Проверить, что без ключа она проходит.
- Предусловие: пользователь подтвердил, что Actions на GitHub включены.
