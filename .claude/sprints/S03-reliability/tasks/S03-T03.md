# S03-T03 — Фолбэк на SPA: `public/.htaccess`

**Исполнитель:** Лид · **Оценка:** 2 SP · **Статус:** Done
**Зависит от:** T02 · **Ветка:** `sprint/S03-reliability` · **Бывшая:** S02-T14

## Контекст

Хостинг — Timeweb: nginx перед Apache. На прямой заход `/about`, `/projects` и любой неизвестный адрес
Apache отвечает 404 своей страницей «Not Found»: фолбэка на `index.html` нет. Рекрутер по прямой ссылке
на /about видит «Not Found», поисковик получает 404 на адреса из `sitemap.xml`, страницу 404 из S02-T02
при прямом заходе никто не увидит.

Условие старта выполнено 2026-10-30: файловый менеджер показывает скрытые файлы (`.test` виден), своего
`.htaccess` на сервере нет. SSH не нужна.

## Что сделать

- `public/.htaccess` — Vite копирует `public/` в `build/` как есть:
  - существующий файл (ресурсы, `robots.txt`, `sitemap.xml`) отдаётся как есть;
  - маршруты приложения `/about`, `/projects` → `index.html` со статусом **200**;
  - любой другой адрес → `index.html` со статусом **404** (`ErrorDocument`): сайт рисует
    `PageNotFound`, поисковик видит честный 404.
- Список маршрутов дублирует `src/App.jsx` — связь видна с обеих сторон: комментарий в `.htaccess` и в
  `App.jsx` рядом с `<Routes>`.
- Выкладка — пользователь, сразу после задачи, одним файлом в `public_html` через файловый менеджер.
  Переадресацию на HTTPS делает nginx, файл её не затрёт.
- Откат — удалить `.htaccess` в панели.

## Проверка на демо, после выкладки

1. Убедиться, что `.htaccess` лежит в `public_html` рядом с `index.html`.
2. В Git Bash: `bash check.sh https://antoshkindev.ru` — скрипт ниже. Ждём 25 строк `OK`, код выхода 0.
3. Отдельно: `curl -s -o /dev/null -w '%{http_code} %{redirect_url}\n' http://antoshkindev.ru/` → 301 на
   `https://antoshkindev.ru/`.
4. Если в ответ по-прежнему старая страница Apache на 196 байт — повторить с `?nocache=1`: может кешировать
   nginx. **Если где-то 500 — сразу удалить `.htaccess` в панели**, потом разбираться.

```bash
#!/usr/bin/env bash
# Проверка ответов сервера для S03-T03. $1 — базовый адрес, $2 — папка сборки.
BASE=${1:?base url}
BUILD=${2:-D:/react-js-projects/my-portfolio-react/build}
JS=$(ls "$BUILD/assets" | grep -E '^index-.*\.js$' | head -1)
fail=0

# path, ожидаемый код, вид проверки тела (app | file | hidden), файл сборки
check() {
  local path="$1" want="$2" kind="$3" file="$4"
  local tmp out code ctype size note ok=1 v
  tmp=$(mktemp)
  out=$(curl -s -o "$tmp" -w '%{http_code}|%{content_type}' "$BASE$path")
  code=${out%%|*}
  ctype=${out#*|}
  size=$(wc -c <"$tmp" | tr -d ' ')
  case "$kind" in
    app)
      [ "$code" = "$want" ] || ok=0
      if grep -q 'id="root"' "$tmp"; then note='index.html сайта'; else note='НЕ index.html сайта'; ok=0; fi
      ;;
    file)
      [ "$code" = "$want" ] || ok=0
      if cmp -s "$tmp" "$BUILD$file"; then note="= build$file"; else note="отличается от build$file"; ok=0; fi
      ;;
    hidden)
      if grep -q 'RewriteRule' "$tmp"; then note='отдаёт содержимое .htaccess'; ok=0; else note='содержимое не отдаёт'; fi
      ;;
  esac
  rm -f "$tmp"
  if [ $ok = 1 ]; then v=OK; else v=FAIL; fail=1; fi
  printf '%-4s %-26s %s (ждём %s) %7sB  %-34s %s\n' "$v" "$path" "$code" "$want" "$size" "$ctype" "$note"
}

check / 200 app
check '/?lang=ru' 200 app
check '/?lang=en' 200 app
check /about 200 app
check '/about?lang=ru' 200 app
check '/about?lang=en' 200 app
check /about/ 200 app
check /About 200 app
check /projects 200 app
check '/projects?lang=ru' 200 app
check '/projects?lang=en' 200 app
check /index.html 200 app
check /no-such-page 404 app
check /about/extra 404 app
check /assets/no-such-file.js 404 app
for f in robots.txt sitemap.xml llms.txt manifest.json favicon.ico logo192.png logo512.png og-cover.png; do
  check "/$f" 200 file "/$f"
done
check "/assets/$JS" 200 file "/assets/$JS"
check /.htaccess 'не 200' hidden
exit $fail
```

Сборка `$2` должна быть та же, что выложена: скрипт сверяет файлы побайтно.
