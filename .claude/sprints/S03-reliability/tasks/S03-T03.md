# S03-T03 — Фолбэк на SPA: `public/.htaccess`

**Исполнитель:** Лид · **Оценка:** 2 SP · **Статус:** To do
**Зависит от:** T02 · **Ветка:** `sprint/S03-reliability` · **Бывшая:** S02-T14

## Контекст

Хостинг — Timeweb: nginx перед Apache. На прямой заход `/about`, `/projects` и любой неизвестный адрес
Apache отвечает 404 своей страницей «Not Found»: фолбэка на `index.html` нет. Рекрутер по прямой ссылке
на /about видит «Not Found», поисковик получает 404 на адреса из `sitemap.xml`, страницу 404 из S02-T02
при прямом заходе никто не увидит.

Условие старта выполнено 2026-10-30: файловый менеджер показывает скрытые файлы (`.test` виден), своего
`.htaccess` на сервере нет. SSH не нужна.

## Что сделать

- `public/.htaccess` — Vite копирует `public/` в `build/` как есть:
  - существующий файл (ресурсы, `robots.txt`, `sitemap.xml`) отдаётся как есть;
  - маршруты приложения `/about`, `/projects` → `index.html` со статусом **200**;
  - любой другой адрес → `index.html` со статусом **404** (`ErrorDocument`): сайт рисует
    `PageNotFound`, поисковик видит честный 404.
- Список маршрутов дублирует `src/App.jsx` — связь видна с обеих сторон: комментарий в `.htaccess` и в
  `App.jsx` рядом с `<Routes>`.
- Выкладка — пользователь, сразу после задачи, одним файлом в `public_html` через файловый менеджер.
  Переадресацию на HTTPS делает nginx, файл её не затрёт.
- Откат — удалить `.htaccess` в панели.

## Критерии приёмки

Проверяются на боевом сайте после выкладки, `curl -s -o /dev/null -w "%{http_code}"`:

- [ ] `/about`, `/about?lang=en`, `/projects` → 200, в ответе `index.html` сайта.
- [ ] `/no-such-page` → 404, в ответе `index.html` сайта; в браузере — `PageNotFound`.
- [ ] `/`, `/robots.txt`, `/sitemap.xml`, файл из `/assets/` → 200, как до правки.
- [ ] `http://antoshkindev.ru/` → 301 на `https://`, как до правки.
- [ ] Definition of Done: lint, test:run, build (`build/.htaccess` на месте), `CHANGELOG.md`.
