> ТЗ оформил лид из сообщения пользователя («проверить тех. долг, прибраться по коду, декомпозировать
> слишком большие компоненты») и аудита кода 2026-10-30. Согласовано пользователем 2026-10-30.

## Цель

Прямые ссылки и выкладки не ломают сайт, форма заявок под тестами и без логов, проверки запускаются
сами. Посетитель получает рабочие ссылки и не видит белого экрана; команда меняет код без страха
незаметно сломать единственный способ получить заявку.

## Критерии успеха

- `/about`, `/about?lang=en`, `/projects` по прямой ссылке — 200; `/no-such-page` — 404 со страницей сайта.
- Сбой загрузки файла и ошибка рендера: вместо белого экрана сообщение с кнопкой перезагрузки, RU и EN.
- В бандле нет логов с данными формы; новые ловит lint. На форму есть тесты.
- `npm run lint` — 0 ошибок и 0 предупреждений; `npm audit` — 0 high; CI зелёный на PR.
- `build/` без `.map`; на сервере их тоже нет.
- Высоты страниц совпадают с базой T01, ±2 px, кроме запланированных правок.

## Ограничения и материалы

**Решения пользователя (2026-10-30):**

- цель — надёжность и страховка, а не чистая уборка;
- Error Boundary — один классовый компонент, исключение записывается в `CLAUDE.md`, без новых зависимостей;
- CI — да, GitHub Actions; проверить, что Actions включены, может только пользователь;
- зависимости — только минорные и патчи.

**Доступы:** хостинг — файловый менеджер Timeweb показывает скрытые файлы (`.test` виден, 2026-10-30),
откат `.htaccess` — удалить файл в панели. Макетов нет: вид сайта не меняется, кроме T14 и T15.
