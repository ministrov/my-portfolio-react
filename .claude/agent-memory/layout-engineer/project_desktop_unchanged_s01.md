В спринте S01 («планшет → мобилка») цель и лид требуют: десктоп ≥ 1025 px с мышью визуально не меняется. Единственное исключение — цвет текста в карточках проектов (блок 04). Гайды в `brief.md` при этом иногда пишут CSS прямо в базовое правило блока. Пример — блок 02, шаг 1: `.hero { box-sizing: border-box; min-height: 100svh }`. В базовом правиле это меняет и десктоп: герой стал бы ниже на 128 px, а контент сместился бы.

В T03 (2026-10-16) такие правки ушли в `@media (max-width: 1024px)`, бейдж героя на десктопе скрыт. Решение по показу бейджа на десктопе вынесено лиду.

**Why:** проект desktop-first, и базовые стили и есть десктоп. Буквальное следование гайду ТЗ нарушает цель спринта и раздел scope «десктопный вид … не входит».
**How to apply:** в задачах S01 каждое новое правило из гайда ТЗ проверяй: не попадает ли оно в базу. Если попадает — ограничь медиазапросом ≤1024 (или ≤767, если ТЗ так говорит), убедись замером на 1280, что вид не изменился, и опиши отклонение от гайда в отчёте. Связано: [[project-hero-traps]].
