Найдено в S02-T02 (404, 2026-10-27):

- **`Trans` подставляет `values` в строку до того, как разбирает её как разметку** (`html-parse-stringify` с разрешёнными тегами: имена из `components`, `br/strong/i/p`). В `utils/i18n/index.js` стоит `escapeValue: false`. Значит, если значение пришло от пользователя, например декодированный адрес на 404, `<path style="x">` превращается в настоящий компонент с атрибутом. React получает `style` строкой и падает: белый экран (воспроизведено тестом). `<img onerror=…>` — тег не из разрешённых, он выходит текстом (проверено тестом).
  - Лечится на месте вызова: `tOptions={{ interpolation: { escapeValue: true } }}` + `shouldUnescape`. Тогда значение экранируется для парсера, а текстовые узлы разэкранируются обратно, и `/`, `&`, `"`, `<>` показываются символ в символ.
  - Остаётся одна дыра. Текст внутри тега компонента `Trans` интерполирует ещё раз, уже сырым значением. Поэтому `/{{path}}` в адресе показывается как `//{{path}}`. Падения нет, это косметика.
  - Словари менять не нужно. В `AboutStory` значений нет, там это не нужно.
- **`useLocation().pathname` в браузере закодирован** (`/%D1%81…`), а в `MemoryRouter` хранится как передан. Тест «кириллица читаемая» проверяет декодирование, только если в `initialEntries` передан `encodeURI('/страница')`. Литерал проходит и без `decodeURIComponent`.
- **У `.page-not-found` нет `min-height`.** Решение пользователя от 2026-10-27, раунд 2. Высоты страницы из таблицы ТЗ (986 на 360 и т. п.) сняты ещё с `80vh` и больше не верны. Сейчас: 947 на 360 / 390, 917 на 768, 876 на ≥ 1280. На высоких окнах под подвалом видна сетка фона: 107 px на 768 × 1024, 204 px на 1920 × 1080. Прижатие подвала — задача каркаса (`Layout`).
- **`min-height` на `content-box` с padding считается от контента, а не от всей рамки.** У секции 404 это `80vh` + 113 + 64 px, поэтому правило срабатывало на всех окнах, а лид оценивал «только на высоких». Прежде чем говорить, срабатывает ли `min-height`, смотри `box-sizing` и сравнивай высоту контента без padding.

**Why:** ни одно из этого не видно из кода компонента. Первое противоречит фразе ТЗ «React экранирует, вставка безопасна».
**How to apply:** любой `Trans` с `values`, где значение может содержать `<`, проверяй тестом с `<path style="x">` в значении. Тест адреса — с закодированным входом. Связано: [[project-css-chunk-order]].
