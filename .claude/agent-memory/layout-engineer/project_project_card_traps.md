Ловушки карточки проекта (`src/components/projectCard/`), найдены в S01-T09 (2026-10-22):

- **Атрибуты `width={658} height={imgHeight}` + глобальный `img { width: 100% }` без `height: auto` искажают скриншот** на любой ширине, где колонка картинки не 658 px. На 1024 пропорция была 0,52 при файле 0,72, на 1280 — 0,91 при 0,72. В T09 `height: auto` добавлен только на ≤ 1024. Десктоп ≥ 1025 искажён по-прежнему: в S01 его не трогали, решение за лидом.
- **Потолок кадра на 769–1274 привязан к самому высокому скриншоту.** На ≤ 1274 он 43.75rem (700 px). При 700 px скриншоты с пропорцией 0,8 (Landing Area, Blog, Create X) после `height: auto` теряли низ на ~990–1024. Поэтому лид поднял потолок на ≤ 1024 до 46rem: там 728 px помещаются. Mish (2,1) обрезан всегда, его видимая часть следует за потолком, и это принято. Меняешь ширину колонки или исходники — пересчитай `ширина × 0,8` на 1024.
- **`aspect-ratio` на `.project-card__image` держится благодаря `overflow: hidden`.** У скролл-контейнера автоминимум высоты 0. С `clip` длинный вертикальный скриншот растянул бы кадр 4:5.
- **Фон под карточкой не белый вверху окна.** `body::before` — фиксированное кобальтовое пятно у верхних углов. Graphite (#6e6e6e) на белом даёт 5,1:1. В полосе ~90–190 px от верха окна на 390 (сразу под хедером, слева) — 3,9–4,4:1. Контраст светлого текста меряй по реальному фону вверху экрана, а не по белому.
- **`ProjectsList` проявляет карточки по очереди, `staggerChildren: 0.5`.** Пятая становится видимой только через ~2,6 с после загрузки. Снимок раньше — пустой фон. Жди `opacity === '1'` у `li`.
- **У Ratingus нет tablet/mobile-файлов (`srcSet=""`).** Браузер пропускает такой `<source>` и берёт десктопную `img` 1200×900.

**Why:** ничего из этого не видно при чтении CSS; проявляется только в замерах на конкретных ширинах.
**How to apply:** правишь картинку или потолок кадра — меряй отрисованную и натуральную пропорцию всех 8 карточек на 769/900/1024/1280 и срез снизу. Цвет вторичного текста — проверяй в верхней полосе окна. Связано: [[project-desktop-unchanged-s01]], [[project-touch-verification]].
